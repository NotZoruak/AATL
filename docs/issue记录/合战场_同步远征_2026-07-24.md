# 合战场开启同步远征后自动结束

- **Issue**: [#3](https://github.com/NotZoruak/MATR/issues/3)
- **提交者**: scherrershin
- **提交时间**: 2026-07-24 19:00 (UTC+8)
- **版本**: v0.6.1
- **标签**: bug

## 问题描述

合战场运行期间，远征归来后画面停留在远征界面，之后合战场报任务失败（0 成功，1 失败）。运行 1–3 小时均复现。远征间隔设为 1200s。

## 分析

`E_CheckTimerExpired` 在合战场主循环中的位置：

```
S_IsHome → E_CheckTimerExpired
              ├─ next: S_NavigateToSortie
              └─ on_error: Expedition
```

两次计时器到期均正确触发 on_error 跳转 Expedition 管线。第一次正常，第二次 24 秒后任务失败，tasker 状态为 SUCCEEDED（管线自行结束）。

推测与远征归来动画时序有关：S_IsHome 匹配到本丸的同时远征归来动画正在播放，动画屏蔽点击操作，导致 Expedition 管线入口识别循环等待，动画结束后进入远征结果画面，后续管线处理异常导致未能正确回到合战场主循环。
