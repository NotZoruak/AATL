# 数据工具设计

## 概述

两个独立的小工具，位于主界面左侧栏，不与 pipeline 任务联动。

- 限锻计算：`_src/MFAAvalonia/ViewModels/Pages/ForgeCalculatorViewModel.cs`
- 数据查找表：`_src/MFAAvalonia/ViewModels/Pages/DataLookupViewModel.cs`

## 限锻计算

### 输入

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 锻刀公式 | 700/700/700/700 | 木炭、玉钢、冷却材、砥石 |
| 当前积分 | 0 | 已有积分，目标 5000 |
| 当前资源 | 0 ×4 | 木炭、玉钢、冷却材、砥石现有量 |
| 当前道具 | 0 ×4 | 梅、竹、松、富士的数量 |
| 手伝札 | 0 | 委托符数量 |
| 加速符 | 0 | 加速符数量 |

### 计算逻辑

1. 剩余积分 = 5000 - 当前积分
2. 按御札优先级依次消耗：富士(60点) → 松(20点) → 竹(15点) → 梅(10点) → 无御札(5点)
3. 计算总锻刀次数 × 单次配方消耗 = 总资源需求
4. 输出还缺多少资源、手伝札（每10次省1张）、加速符

### OCR 识别

`RecognizeScreen()` 从连接的游戏画面中 OCR 读取当前积分和资源数值，自动填入输入框。

## 数据查找表

两个数据表，静态展示：

| 表 | 内容 |
|----|------|
| 极化升级经验 | 各刀剑男士从 LV1 到 LV99 所需累计经验值 |
| 远征收益 | 各地图远征的资材、经验、小判等收益对比 |

纯前端数据展示，无 pipeline 交互。
