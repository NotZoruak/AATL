# 联队战（陆联）任务设计

## 概述

- 流水线文件：`resource/base/pipeline/LRentaisen.json`
- 入口节点：`LRentaisen`
- 节点前缀：`LR_`
- 总节点数：约 80

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 换队长 | 复选框 | 通过筛选装备马的刀剑来切换队长 |
| 部队交替 | 复选框 | 在行动选择界面自动切换部队，需同时填写队伍序列 |
| 选择部队 | select | 选择出阵部队（第1轮使用），部队一~四 |
| 队伍序列 | input | 9位数字（每位1-5），表示第2-10轮分别使用哪个部队，例如121212121 |
| 选择难度 | select | 易/普/难/超难，默认超难 |

## 活动入口与难度选择（双重验证）

## TeamSwitchAction 自定义动作

`TeamSwitchAction.cs` — 部队交替逻辑：
1. OCR 剩余轮次（ROI `[114, 39, 28, 25]`）
2. 根据剩余轮次查配置表（`team_config`，9 位数字如 `221222111`，第 2-10 轮分别使用的队伍）
3. 双击对应队伍标签（间隔 500ms）
4. 点击确认按钮 `[931, 353, 1, 1]`

五个队伍标签坐标：`[850, 479]`、`[1007, 475]`、`[1167, 473]`、`[931, 608]`、`[1077, 606]`

## CaptainDamageAction 自定义动作

`CaptainDamageAction.cs` — 命中重伤后输出日志 `"检测到队长重伤，撤退撤退"` 到 GUI 面板。

## 闪退恢复节点（仅改前缀，复用合战场）

| 节点 | 类型 | 行为 |
|------|------|------|
| `LR_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭，timeout=3000 |
| `LR_IsLoginReward` + Click2 + Click3 | TemplateMatch + Click×2 | 三击关闭 |
| `LR_HasExpeditionReturn_Exp` | OCR `"经验"` ROI [388,59,54,25] | 点击关闭 |
| `LR_HasExpeditionReturn_Title` | OCR `"远征结果"` ROI [558,1,162,52] | 点击关闭 |
| `LR_IsGameIcon` | TemplateMatch 全屏 | 点击重进，post_delay=3000 |
| `LR_IsLoginButton` | TemplateMatch | 点击登录，post_delay=3000 |
| `LR_IsGameUpdatePopup` | TemplateMatch | 关闭商店更新，post_delay=2000 |
| `LR_IsInGameUpdatePopup` | OCR `"更新"` | 关闭游戏内更新，post_delay=2000 |
| `LR_IsInternalReport` | TemplateMatch | 点击关闭 |
| `LR_IsConnectionInterrupted` | OCR `"连接中断"` | 点击重连 |
| `LR_FallbackWait` | DirectHit | DoNothing → 回枢纽 |

## 延迟优化记录

| 节点 | 原延迟 | 现延迟 | 原因 |
|------|--------|--------|------|
| `LR_IsActionSelect` | pre=500, post=500 | pre=100, post=100 | DoNothing 不需要等 |
| `LR_ClickContinueBattle` | pre=500, post=500 | pre=100, post=100 | 同一帧截图上重复 OCR 浪费 |
| `LR_AfterCaptain` | pre=100 | pre=500, post=500 | 点即刻出阵后等弹窗出现 |
| `LR_ClickReplenishConfirm` | pre=100 | pre=500 | 等购买确认弹窗出现 |

## 实现变更记录

| 变更 | 说明 |
|------|------|
| 补给弹窗 | 新增 `LR_IsSupplyPopup`，主枢纽第二位，post_delay=500 |
| 难度双重验证 | 新增 `LR_VerifyDifficulty`，点击难度后同模板同 ROI 复核 |
| 重伤检测 | 新增 `LR_CheckCaptainDamage` + `CaptainDamageAction`，换队后/行动前检测 |
| 特殊掉落正则 | expected `"完成\|撤退"`，匹配两种终止文本 |
| 选项重排 | 换队长→部队交替→选择部队→队伍序列→选择难度 |
| Verify 节点兜底 | `LR_VerifyDifficulty`、`LR_VerifyEventPage`、`LR_VerifyMenuClosed`、`LR_VerifyHomeMenuClosed` 的 `next` 追加 `LR_DetectWhereAmI`，验证失败立刻跳回检测循环 |
| 标签改名 | `LR_换队配置` label 改为 `"队伍序列"` |
| ActionSelect 延迟 | 两次 500→100，每轮省 800ms |
| 右键确认补充 | `LR_ClickReplenishConfirm` 确认前等 500ms |
| 任务说明 | 警告游戏自行使用道具，避免重复消耗 |
| LR_ClickDifficulty 兜底 | `next` 追加 `LR_DetectWhereAmI`，添加 `on_error`；`LR_VerifyDifficulty` 复核失败后立即跳回检测循环，不再等 20s 超时 |
| LR_ActionSelectHub 兜底 | `next` 追加 `LR_DetectWhereAmI`，OCR "重伤"/"战斗" 全失败时兜底 |
| LR_IsEventPage 兜底 | `next` 追加 `LR_DetectWhereAmI`，TemplateMatch 失败时兜底 |
| LR_CheckSwordDropAfterSpecial | 新增 `pre_delay=1000`，`next` 追加 `LR_DetectWhereAmI`；补充缺失的 `LR_IsSwordDropAfter`（ColorMatch）节点文档 |
