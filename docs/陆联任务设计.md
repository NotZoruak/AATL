## 主流程链路

```
LR_DetectWhereAmI（枢纽）
   ├── 本丸 → LR_IsHome → LR_NavigateToActivity
   │
   ├── 活动页 → LR_IsEventPage（TemplateMatch 联队战.png）
   │     → LR_SelectDifficulty → LR_ClickDifficulty → LR_VerifyDifficulty
   │       → LR_EnterEvent（点击进入活动，post_delay 800）
   │         → LR_IsTeamSelect（优先） / LR_DetectWhereAmI
   │
   ├── 部队选择 → LR_IsTeamSelect（OCR "部队选择"）
   │     → LR_ClickTeam（post_delay 800）→ LR_CaptainHub
   │       → LR_DragCaptain → LR_IsPreSortieConfirm（OCR "即刻"）
   │         → LR_ClickSortieNow → LR_PostSortieHub
   │
   ├── 行动选择 → LR_IsActionSelect（OCR "战斗"/"重伤"）
   │     → LR_ActionSelectHub → LR_ClickContinueBattle → 行军循环
   │
   ├── 刀剑选择 → LR_IsSwordSelect → LR_ClickCaptain1~5
   │
   ├── 特殊掉落 → LR_IsSpecialDrop → LR_CheckMoreSpecialDrops
   │     → LR_ClickContinueBattle
   │
   ├── 令牌补充 → LR_IsTicketPopup → LR_HandleTicketPopup
   │     → LR_ClickRestore3 / LR_ReplenishOrTerminate
   │
   └── 闪退恢复 / 弹窗关闭 / LR_FallbackWait
```

## 活动页进入战斗

`LR_IsEventPage` TemplateMatch `联队战.png`（ROI `[427,69,388,52]`，阈值 0.98）。

`LR_SelectDifficulty` 由 GUI「选择难度」override `LR_ClickDifficulty.target` 控制点击位置（易/普/难/超难）。

`LR_VerifyDifficulty` TemplateMatch `联队战.png` 二次验证仍在活动页。命中 → `LR_EnterEvent`（点击 `[1141,614,120,49]`），post_delay 800。

```json
"LR_EnterEvent": {
    "action": { "type": "Click", "param": { "target": [1141, 614, 120, 49] } },
    "pre_delay": 500,
    "post_delay": 800,
    "next": ["LR_IsTeamSelect", "LR_DetectWhereAmI"]
}
```

`LR_IsTeamSelect` 排在首位，优先检测部队选择页；命中后在此检查远征后台计时器（`E_CheckTimerExpired`），避免过场动画中计时器到期导致 `E_GoHome` 失败。

## 部队选择与换队长

`LR_IsTeamSelect` OCR "部队选择"（ROI `[561,1,160,49]`）→ `LR_ClickTeam` 点击对应部队标签（GUI override target），post_delay 800。

```json
"LR_ClickTeam": {
    "action": { "type": "Click", "param": { "target": [154, 93, 1, 1] } },
    "next": ["LR_CaptainHub"],
    "pre_delay": 100,
    "post_delay": 800
}
```

`LR_CaptainHub` 路由到 `LR_DragCaptain`（Custom 拖拽换队长）或 `LR_IsPreSortieConfirm`。`LR_DragCaptain` on_error → `LR_DetectWhereAmI`。

```json
"LR_CaptainHub": {
    "on_error": ["LR_DetectWhereAmI"],
    "next": ["LR_ClickCaptainSlot", "LR_IsPreSortieConfirm"]
}
```

## 行动选择与部队交替

`LR_IsActionSelect` OCR "战斗"（ROI `[1040,584,107,57]`）→ `LR_ActionSelectHub`：

```json
"LR_ActionSelectHub": {
    "on_error": ["LR_DetectWhereAmI"],
    "next": ["LR_ClickSwitchTeam", "LR_CheckCaptainDamage", "LR_ClickContinueBattle", "LR_DetectWhereAmI"]
}
```

`LR_CheckCaptainDamage` Custom 检测队长重伤，命中 → `LR_RetreatOnCaptainDamage`（撤退），未命中 → 继续。

`LR_RunTeamSwitch` 部队交替路由，`next: ["LR_CheckCaptainDamage", "LR_ClickContinueBattle"]`，`on_error → LR_DetectWhereAmI`。

`LR_ClickContinueBattle` OCR "战斗" 点击进入下一轮，next → `LR_DetectWhereAmI`。

## 特殊掉落

`LR_CheckMoreSpecialDrops` → `LR_CheckSwordDropAfterSpecial` → `LR_IsSwordDropAfter` / `LR_WaitForEventPage`。特殊掉落全清后回到 `LR_DetectWhereAmI`。

## 令牌补充

`LR_IsTicketPopup` TemplateMatch → `LR_HandleTicketPopup`（`next: ["LR_ReplenishTicket", "LR_TerminateNoTicket"]`）→ `LR_ClickRestore3`（购买三枚，自循环直到成功）/ 次数耗尽终止。

## 刀剑选择

`LR_IsSwordSelect` OCR "刀剑男士选择"（ROI `[530,6,224,45]`）→ `LR_ClickCaptain1~5` 依次点击队长位。

## 导航链路

本丸检测（ColorMatch 亮度 + TemplateMatch `本丸.png`）→ `LR_NavigateToActivity`（`on_error → LR_DetectWhereAmI`）→ `LR_ClickMenu`（OCR "目" ROI `[1183,18,87,40]`）→ `LR_PostClickMenuHub` → `LR_VerifyMenuSortie` → `LR_ClickSortieInMenu`（OCR "出阵"）→ `LR_VerifyMenuClosed`。

```json
"LR_PostClickMenuHub": {
    "on_error": ["LR_DetectWhereAmI"],
    "next": ["LR_VerifyMenuSortie", "LR_CheckNavDirForRetry", "LR_DetectWhereAmI"]
}
```

## 排序与换队长

换队长流程：`LR_DetectSortOrder` → `LR_ClickDescending`（OCR "降序"，排序降序）→ `LR_ConfirmSortAsc`（OCR "升序"，确认已完成排序）→ `LR_DragCaptain`（Custom 拖拽换队长）。

```json
"LR_DetectSortOrder": {
    "on_error": ["LR_DetectWhereAmI"],
    "next": ["LR_ClickDescending", "LR_ConfirmSortAsc"]
}
```

## on_error 覆盖

- 主枢纽 next 列表中节点不设 on_error
- 主枢纽 `on_error → LR_RestartGame`
- `LR_IsHome`、`LR_PostClickMenuHub`、`LR_DetectSortOrder`、`LR_CaptainHub`、`LR_CheckMoreSpecialDrops`、`LR_ActionSelectHub`、`LR_NavigateToActivity`、`LR_ClickMenu` → `LR_DetectWhereAmI`
- `LRentaisen` 入口节点、`LR_ReplenishOrTerminate`、`LR_HandleTicketPopup`、`LR_PostSortieHub` 无需 on_error

## 同步远征集成

启用后 `LR_IsHome.next` 改为 `["Expedition"]`，`E_AllTeamsBusy.next` 改回活动页入口。计时器在全部忙线后启动，活动页命中 `LR_IsTeamSelect` 时检查。详见远征设计文档。

## 设计要点

- **计时器在部队选择页检查**：`LR_IsTeamSelect` → `E_CheckTimerExpired`，避免过场动画中触发
- **进入活动后优先匹配部队选择页**：`LR_EnterEvent.next` 首位 LR_IsTeamSelect
- **LR_ClickTeam post_delay 800**：点击部队标签后等待切换动画
- **部队交替**：`LR_RunTeamSwitch` 在行动选择界面切换部队并处理队长重伤
- **令牌自动购买**：`LR_HandleTicketPopup` → `LR_ClickRestore3`
- **节点重命名**：`LR_ClickUndergroundInMenu` → `LR_ClickActivityInMenu`，`LR_NavigateToUnderground` → `LR_NavigateToActivity`
