# 工作记录页设计

## 状态

设计定稿,待实施。「本丸仓库」侧边栏入口与占位页已完成(2026-08-20);本设计定义「工作记录」子页的日志解析模块与展示(首版:解析+展示,不含保存归档)。

## 背景与目的

「本丸仓库」的「工作记录」页(原名「运行结果」,2026-08-20 改名)用于查看小白执行任务的结果:左侧为按任务拆分的运行记录列表,右侧为选中记录的统计卡片。

数据源为词表打点日志(见 `docs/node命中日志打点设计.md`):打点侧在关键 node 命中时写入统一格式 `[前缀] 行为词 附加信息` 的文件日志行,本模块负责把这些词表行与任务结构行组合成运行记录。

解析链路:`原始日志 → 行事件 → 运行记录 → 页面卡片`。

## 数据源:日志结构与锚点行

日志文件按天切分:`debug/logs/log-YYYYMMDD.log`。行格式:

```
[2026-08-20 00:20:44.568][INF] [cfg=Default] 内容
```

解析所需的锚点行(全部为既有日志,无需新增打点):

| 行特征 | 含义 |
|---|---|
| `[任务管线合并] 任务#N 名称=[X] 入口=[Y] 参数=[` | 任务定义:任务名 X、入口 pipeline Y,一条记录的开始 |
| `开始任务：X`(src=Monitor) | 任务第 N 轮开始(同一任务连跑多轮) |
| `停止前状态：S` | 队列整体结束,S 为状态码 |
| `[前缀] 行为词 附加信息` | 词表打点行,计入当前记录统计 |

状态码映射:`SUCCEEDED → 成功`、`STOPPED → 手动停止`、`FAILED → 失败`、`NOT_STARTED → 未开始`;记录期间出现 `[中断]` 词条 → 覆盖为「中断」。

## 记录模型与统计口径

一条工作记录 = 队列中一个任务从开始到结束(按任务拆,用户确认)。

- 开始:该任务的 `[任务管线合并] 任务#N` 行时间
- 结束:下一条任务定义行时间,或 `停止前状态` 行时间
- 同一任务连跑多轮(重复次数)合并为一条记录;同一任务名跨队列(用户停止后重启)按「任务管线合并」批次区分,不合并

### 出阵统计

| 字段 | 口径 |
|---|---|
| 出阵次数 | `出阵` 词条计数 |
| 行军次数 | `点击行军` 词条计数 |
| 完成圈数 | `完成一圈` 计数;没有该词条的任务(地下城、合战场过去模式)用出阵次数 |
| 提前结束次数 | 终止类词条计数(无票终止/全部队伍不符合要求终止/队长重伤撤退) |
| 资源收获 | `资源点获取 名称x数量` 按资源名聚合,同资源多次出现数量累加(两次 `木炭x120` 记为 `木炭x240`),小判箱掉落计数并入,如 `木炭x240 玉钢x60 小判箱x3` |

### 刀剑掉落统计

`刀剑掉落 刀种 刀名` 词条按刀种分组聚合:

```
刀剑掉落统计(共 5 把)

太刀:狮子王(x2),鬼丸国纲(x1)
短刀:今剑(x1),后藤藤四郎(x1)
```

- 刀种顺序固定:短刀 → 胁差 → 打刀 → 太刀 → 大太刀 → 枪 → 薙刀 → 剑(用户指定)
- 同种刀名逗号分隔,每把带 xN 计数;没有掉落的刀种不显示

### 后勤记录

`[后勤]` 前缀词条计入后勤记录(归组依据是产生记录的任务类型,同步后勤产生也计入)。按行为词分组计数,「派遣远征」展开明细:

```
后勤记录
  派遣远征 ×3
    12:01  部队3 → 4-3
    12:02  部队1 → 2-1
  修刀 ×1
```

「派遣远征」明细解析词条附加信息 `部队3已派遣至 4-3`,拆出部队号与地图号。

### 特殊情况

- 当前记录内 Warning 词条明细(重伤撤退/道中撤退/刀装破坏撤退/刀装近破坏撤退/疲劳撤退/修刀等)
- `[中断]` 事件明细(任务异常停止/闪退恢复/卡死恢复):按时间戳关联到所在记录,被中断任务的运行结果显示「中断」

## 页面布局与卡片顺序

```
┌─────────────────────────────────────────────────────────┐
│ 工作记录                                    [刷新记录]  │
├──────────────────────┬──────────────────────────────────┤
│ 记录列表(左)          │ 统计卡片(右,选中后显示)           │
│ 08-18 12:00—13:27    │ ┌──────────────────────────────┐ │
│   地下城             │ │ 任务概况                     │ │
│ 08-18 13:30—13:40    │ │ 任务:地下城                  │ │
│   后勤               │ │ 时间:08-18 12:00—13:27      │ │
│ ...(时间倒序)         │ │ 耗时:1 小时 27 分            │ │
│                      │ ├──────────────────────────────┤ │
│                      │ │ 出阵统计                     │ │
│                      │ │ 出阵 8 次 / 完成 8 圈         │ │
│                      │ │ 提前结束 0 次                │ │
│                      │ │ 资源收获:木炭x120 玉钢x60    │ │
│          小判箱x3            │ │
│                      │ ├──────────────────────────────┤ │
│                      │ │ 刀剑掉落统计                 │ │
│                      │ ├──────────────────────────────┤ │
│                      │ │ 后勤记录                     │ │
│                      │ ├──────────────────────────────┤ │
│                      │ │ 特殊情况                     │ │
│                      │ └──────────────────────────────┘ │
└──────────────────────┴──────────────────────────────────┘
```

交互细节:

- 列表每行:「开始时间—结束时间 + 任务名」,时间倒序;非成功状态在任务名后标注,如「地下城 (中断)」
- 选中行显示对应统计卡片
- 「刷新记录」按钮:重新扫描 `debug/logs/log-*.log` 全部日志并重建列表
- 任务概况不显示「结果:成功」(无信息量,已确认去掉)

### 小判箱掉落(地下城专属,并入资源收获)

打点规格(2026-08-20 已实施):`U_DetectWhereAmI.next` 挂 `U_IsKobanChest`(位于 U_IsSwordDropColor 之后),模板 `Activity/小判箱掉落.png` ROI `[414,285,38,37]` 匹配,命中后内嵌 LogAction 输出 `[地下城] 小判箱掉落` 并点击 `[403,335,68,26]`,wait_freezes 200ms。

解析侧:`小判箱掉落` 词条计数并入「资源收获」聚合,显示为 `小判箱xN`(与资源点获取的 `木炭x120` 并列)。

## 实现结构

```
LogParser            读日志文件 → 行事件流(时间/级别/内容)
WorkRecordBuilder    行事件流 → List<WorkRecord>(锚点行切分、词条归组、统计聚合)
WorkRecordsViewModel 刷新命令、选中记录、卡片字段绑定
WorkRecordsView      左侧列表 + 右侧卡片布局
```

解析器与聚合器为纯逻辑类,不依赖 UI,可独立测试。

## 边界情况

- 任务定义行存在但无任何词条(如启动后立即停止):记录正常显示,统计为 0
- 日志跨天:按 `log-YYYYMMDD.log` 文件名顺序合并扫描
- 时间戳缺失/格式异常:跳过该行,不中断解析
- 同一任务名连续两段:按「任务管线合并」批次区分
- `停止前状态:NOT_STARTED`:记录生成,状态显示「未开始」
- 词条无法解析(如派遣远征附加信息异常):该条计入计数但明细留空

## 测试策略

用真实日志片段构造输入(从 `debug/logs/` 摘取含各任务词条的实际行),断言:记录切分、出阵/圈数/提前结束计数、资源聚合、掉落分组与刀种顺序、派遣远征明细、中断关联与状态覆盖、跨批次同名任务不合并、无词条记录。

## UI视觉与布局补充(2026-08-20)

### 导航命名

本丸仓库区域的上级入口名称确定为「本丸」,使用小房子图标。工作记录页不再额外增加页面图标,下级页面使用文字导航或页签:

```
本丸
├─ 仓库
├─ 工作记录
└─ 刀帐
```

打开工作记录时,只突出显示「工作记录」;「本丸」保留上级入口状态,不与当前页面使用同等强度的选中样式。

### 页面总体布局

工作记录页采用「左侧记录列表卡片 + 右侧详情卡片」布局。左右两侧均放在卡片容器内,保持页面边界和留白规整:

```
┌──────────────────────┬────────────────────────────────┐
│ 工作记录              │ 任务概况                       │
│ [刷新记录]            │                                │
│                      │ 出阵收获                       │
│ 记录列表              │                                │
│                      │ 后勤记录                       │
│                      │ 特殊情况                       │
└──────────────────────┴────────────────────────────────┘
```

- 左侧记录列表卡片固定宽度,内部独立滚动;右侧详情区域独立滚动。
- 左侧卡片标题为「工作记录」,右上角使用按钮形式的「刷新记录」,不使用普通超链接。
- 记录按时间倒序排列。
- 记录项采用紧凑的两行结构,第一行显示任务名与状态,第二行显示时间范围与耗时。
- 选中记录使用浅蓝背景和左侧蓝色竖线标记,移除右侧圆形对勾。
- 记录列表项不设置过大的上下内边距,避免左侧出现大面积空白。

### 右侧卡片顺序与内容

右侧详情固定按以下顺序显示:

1. 任务概况
2. 出阵收获
3. 后勤记录
4. 特殊情况

#### 任务概况

任务概况单独占一张卡片并放在最上方,包含任务信息和出阵统计:

```
任务概况

地下城                         手动停止
08-20 14:59–15:10 · 10 分钟

出阵次数：1       行军次数：9       完成圈数：2
```

- 任务名与状态在同一行显示。
- 时间范围与耗时在第二行显示。
- 出阵次数、行军次数、完成圈数、提前结束次数在底部同一行显示。
- 提前结束次数为 0 时不显示该字段,不保留空白占位;相关异常仍归入「特殊情况」卡片。
- 不再将出阵统计拆成单独卡片。

#### 出阵收获

资源收获与刀剑掉落合并为一张「出阵收获」卡片,但不使用左右对半布局:

```
出阵收获

资源收获
木炭 ×120　玉钢 ×80　冷却材 ×30　小判 ×600

刀剑掉落
短刀：秋田藤四郎（×3）、平野藤四郎（×1）、爱染国俊（×1）
胁差：鲶尾藤四郎（×2）
打刀：歌仙兼定（×1）、鸣狐（×1）、山姥切国广（×1）
太刀：山伏国广（×1）、狮子王（×1）
大太刀：石切丸（×1）
```

- 资源收获使用一行横向排列,资源名与数量之间保留清晰间距。
- 刀剑掉落占用卡片完整宽度,按刀种分组,每个刀种一行;内容过长时自然换行。
- 刀剑掉落不为每把刀剑创建独立小卡片,避免掉落较多时产生过多视觉元素。
- 资源收获为空时隐藏资源收获区块,刀剑掉落仍占用完整宽度。

#### 后勤记录

后勤记录单独占一张卡片。该卡片只展示由「同步后勤」功能产生的记录,不与任务概况或出阵收获合并:

```
后勤记录

检查队伍状况（×1）
远征成功（×2）
获得资源（×3）
```

#### 特殊情况

特殊情况单独占一张卡片,用于显示重伤撤退、刀装破坏撤退、疲劳撤退、任务中断等异常或 Warning 记录。没有内容时隐藏整张卡片。

### 空内容卡片显示规则

右侧所有卡片均采用条件显示,没有内容时隐藏,不显示空白卡片:

- 后勤任务没有出阵收获时,隐藏「出阵收获」卡片。
- 任务没有后勤记录时,隐藏「后勤记录」卡片。
- 任务没有特殊情况时,隐藏「特殊情况」卡片。
- 任务既没有资源收获也没有刀剑掉落时,隐藏「出阵收获」卡片。
- 任务概况始终显示,因为它包含任务名称、状态、时间和耗时等基础信息。
- 当详情卡片全部为空时,在任务概况下方显示轻量提示「暂无详细记录」,不创建额外大卡片。

### 视觉风格

整体采用浅色、低对比度边框、紧凑卡片的桌面工具风格:

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F5F7FB` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#172033` |
| 辅助文字 | `#667085` |
| 主强调色 | `#356AE6` |
| 边框 | `#E4E8F0` |
| 成功状态 | `#16A34A` |
| 警告状态 | `#D97706` |
| 异常状态 | `#D92D20` |

- 卡片圆角建议为 10–14px,所有卡片保持一致。
- 卡片使用 1px 浅色边框区分层次,阴影保持轻微,不使用明显悬浮效果。
- 页面内容区内边距建议为 24–32px;卡片之间使用 16–20px 间距。
- 卡片内部采用 16–24px 内边距,任务概况和资源收获使用更紧凑的上下间距。
- 不使用渐变、发光或大面积高饱和色块。
- 选中状态只使用浅蓝背景、左侧蓝色标记和蓝色文字,避免同时使用多个强烈图形标记。
- 状态标签使用浅色背景配合对应颜色文字,不要把整条记录染成状态色。
- 标题层级清晰:卡片标题突出,字段名称使用辅助文字,数值和刀剑名称使用主文字。
- 右侧卡片高度由实际内容决定,不设置过大的统一最小高度,避免内容较少时出现大片空白。
