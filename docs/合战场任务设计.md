# 合战场（Sortie）任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/Sortie.json`
- 入口节点：`Sortie`
- 主枢纽：`S_DetectWhereAmI`
- 副枢纽：`SF_DetectWhereAmI`（刀装补充后专用）
- 节点前缀：`S_` / `SF_`

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| S_选择时代 | select | 维新的记忆～延享的记忆 |
| S_选择地域 | select | 各地域 |
| S_选择部队 | select | 部队一～五 |
| S_选择阵形 | select | 各阵形 |
| S_重伤处理 | select | 修刀 / 停止 / 撤退 |
| S_刀装破坏处理 | select | 停止 / 补充刀装 / 刀装保护 / 补充+刀装保护 |
| S_疲劳处理 | select | 无 / 刷花 / 停止 |
| S_换队长 | checkbox | 启用队长拖拽切换 |
| S_王点前撤退 | checkbox | 到达王点前自动撤退 |
| S_道中撤退 | checkbox | 道中特定点撤退 |
| S_同步远征 | checkbox | 行军完成后回本丸检查远征 |

## 主枢纽 `S_DetectWhereAmI`

26 个检测节点，`timeout: 120000`（可由全局选项"卡死等待时间"覆盖），`on_error → S_RestartGame`。

```json
"S_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["S_RestartGame"],
    "next": [
        "S_IsAnnouncementPopup", "S_IsTrainingLetter",
        "S_IsLoginReward", "S_HasExpeditionReturn_Exp",
        "S_IsMarching", "S_IsBattleResult_Exp",
        "S_IsBattleResult_Title", "S_IsSwordDropColor",
        "S_IsKebiishi", "S_IsFormationSelect",
        "S_IsSwordSelect", "S_IsTeamSelect",
        "S_IsEraSelect", "S_IsRegionSelect",
        "S_IsSortieActivity", "S_IsMenuDirectory",
        "S_IsTeamStatusPanel", "S_CheckHomeBrightness",
        "S_IsRepair", "S_IsStopOnDamage",
        "S_IsGameIcon", "S_IsLoginButton",
        "S_IsGameUpdatePopup", "S_IsInGameUpdatePopup",
        "S_IsInternalReport", "S_LeaveTroopRecord",
        "S_FallbackWait"
    ]
}
```

## 主流程链路

```
S_DetectWhereAmI（枢纽）
   ├── 本丸 → S_IsHome → S_NavigateToSortie
   │     → S_ClickMenu（OCR "目"）→ S_PostClickMenuHub
   │       → S_VerifyMenuSortie / S_CheckNavDirForRetry
   │     → S_ClickSortieInMenu（OCR "出阵"）→ S_VerifyMenuClosed
   │       → S_TryClickSortie
   │
   ├── 时代选择 → S_IsEraSelect → S_ClickEra → S_ConfirmEra
   │
   ├── 地域选择 → S_IsRegionSelect → S_VerifyRegionSelect → S_ClickRegion
   │
   ├── 部队选择 → S_IsTeamSelect → S_ClickTeam
   │     → S_IsSwordSelect → S_DetectSortOrder
   │
   ├── 换队长 → S_CaptainHub → S_DragCaptain / S_IsPreSortieConfirm
   │     → S_ClickSortieNow
   │
   ├── 刀装补充 → S_CheckEquipmentPopup → S_PreCheckTroopRecord
   │     → S_PreCheckUseRecord → S_PreCheckClickRecordN
   │     → S_PreCheckUseRecordBtn → SF_DetectWhereAmI
   │
   ├── 行军 → S_PostSortieHub → S_DetectAfterSortieNow
   │     → S_IsTroopDepleted → S_IsMarching
   │       ├── S_IsMarchingDamage（重伤→撤退）
   │       ├── S_FatigueDetect（疲劳→回本丸）
   │       ├── S_EqCheck → 18 ColorMatch + Template（刀装→回本丸）
   │       ├── S_CheckBoss → 39 Boss/MidRetreat 节点
   │       └── S_PostClickMarching（兜底前进）
   │
   ├── 重伤处理 → S_IsPreDamage → 修刀/停止/撤退
   │
   ├── 回本丸 → S_ReturnHome → S_ClickMenuFromRepair
   │     → S_ClickHomeInMenu
   │
   └── 闪退恢复 / 弹窗关闭 / S_FallbackWait

同步远征：S_IsHome.next → Expedition，计时由 E_CheckTimerExpired + SmartWaitAction 控制
```

### 出阵准备

```
本丸 → S_CheckHomeBrightness → S_IsHome → S_NavigateToSortie
  → S_ClickMenu（OCR "目"）→ S_PostClickMenuHub
    → S_VerifyMenuSortie / S_CheckNavDirForRetry / S_DetectWhereAmI
  → S_ClickSortieInMenu（OCR "出阵"）→ S_VerifyMenuClosed
    → S_TryClickSortie → S_DetectWhereAmI
```

`S_PostClickMenuHub` 三个分支：验证排序菜单、导航方向重试、兜底回枢纽。`S_TryClickSortie` 失败时回退重试 OCR "出阵"。

### 时代/地域/部队选择

`S_IsEraSelect` → `S_ClickEra` → `S_ConfirmEra`。`S_IsRegionSelect` → `S_VerifyRegionSelect` → `S_ClickRegion`。`S_IsTeamSelect` → `S_ClickTeam`（target 坐标由 GUI 选项覆盖）。`S_IsSwordSelect` → `S_DetectSortOrder`（排序策略）。

### 换队长

`S_CaptainHub`（enabled 由 `S_换队长` 选项控制）→ `S_DragCaptain` / `S_IsPreSortieConfirm`。`S_DragCaptain` 调 `DragCaptainAction` 自定义动作，按选项在「马匹筛选」和「队内拖拽」间切换。

### 刀装补充

`S_刀装破坏处理` 选「补充刀装」或「补充+刀装保护」时，通过 pipeline_override 启用整条链路：

```
S_CheckEquipmentPopup（TemplateMatch "整备刀装.png"）
  → S_PreCheckTroopRecord → S_PreCheckUseRecord
  → S_PreCheckClickRecordN → S_PreCheckUseRecordBtn
```

先翻部队记录确认当前刀装状态，再逐个补充缺失的刀装。补充完成后跳转副枢纽 `SF_DetectWhereAmI`，结构与主枢纽相同（独立 next 列表 + `on_error → SF_RestartGame`），负责刀装修复后的继续行军流程。

### 副枢纽 `SF_DetectWhereAmI`

刀装补充完成后专用枢纽，节点前缀 `SF_`。`on_error → SF_RestartGame`，重启后回到 `SF_DetectWhereAmI`。

### 行军

```
S_PostSortieHub（出战前检查：重伤/刀装弹窗）
  → S_DetectAfterSortieNow
    → S_IsTroopDepleted → S_IsMarching
    → S_FallbackWait → S_DetectWhereAmI
```

`S_IsMarching` 的 next 按顺序串联：

```
S_IsMarching
  → S_IsMarchingDamage（重伤）
  → S_FatigueDetect（疲劳，默认 disabled）
  → S_EqCheck（刀装保护，默认 disabled）
  → S_CheckBoss（王点/道中检测，39 节点）
  → S_PostClickMarching（兜底前进）
```

### 疲劳处理

`S_疲劳处理` 选「刷花」或「停止」时启用 `S_FatigueDetect`：

```
S_IsMarching → S_FatigueDetect（TemplateMatch "重疲劳.png"）
  → S_ReturnHomeFromMarching → S_ConfirmReturnHome → S_ReturnHome
```

扫描行军画面左侧 `ROI [254,154,31,502]`，匹配重疲劳图标（阈值 0.9）。命中后点击回本丸按钮 → 确认返回本丸 → 回到本丸。

此外，部队一出阵前 `S_FatigueCheck`（调 `FatigueCheckAction`）OCR 读取刀剑男士疲劳值，命中阈值则先回本丸刷花再出发。

### 刀装破坏处理

`S_刀装破坏处理` 选「刀装保护」或「补充+刀装保护」时启用 `S_EqCheck` 路由：

```
S_IsMarching → S_EqCheck（路由枢纽）
  ├─ S_EqCheckTemplate（"刀装破坏.png"，阈值 0.85）
  │    已破 → 回本丸
  ├─ S_EqCheckC_R0C0 ~ S_EqCheckC_R5C2（18 个 ColorMatch）
  │    每格检测像素色值 [183,182,182]±1（3 列 × 6 行）
  │    命中 = 刀装接近破坏 → 回本丸
  ├─ S_CheckBoss（正常行军流）
  └─ S_PostClickMarching（兜底）
```

### 重伤处理

| 时机 | 模式 | 流程 |
|------|------|------|
| 出战前 | 修刀 | `S_IsPreDamage` → 修刀 → 回本丸 |
| 出战前 | 停止 | `S_StopOnDamagePopup` → 停止任务 |
| 行军中 | 撤退 | `S_IsMarchingDamage` → 撤退 → 回本丸 |

### 王点/道中撤退

`S_CheckBoss` 路由 39 个检测节点，覆盖维新～延享全部时代的王点（Boss）和道中撤退（MidRetreat）。开启「王点前撤退」时：命中王点 → `S_ClickRetreat` → `S_ConfirmRetreat` → `S_ReturnHome`。命中道中撤退点 → 自动撤退。末尾 `S_PostClickMarching` 兜底继续行军。

### 回到本丸

两条路径：
1. `S_ReturnHome` → `S_ClickMenuFromRepair`（OCR "目"）→ `S_ClickHomeInMenu`（点击 `[1037,169,110,44]`）
2. `S_ClickMenuStop` → `S_ClickHomeStop` → `S_ClickHomeFallback`

### 同步远征

`S_同步远征` 开启后 `S_IsHome.next` 覆写为 `["Expedition"]`，行军回本丸后自动切入远征流程。计时由 `E_CheckTimerExpired` + `SmartWaitAction` 控制：按远征刷新间隔与最近远征剩余时间中更短者调度下一次检查，避免无谓的切屏开销。

## 闪退恢复

枢纽中的完整检测链覆盖游戏意外退出后的各种状态：

| 节点 | 识别 | 动作 |
|------|------|------|
| `S_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `S_IsTrainingLetter` | TemplateMatch `修行书信.png` | 自循环关闭 |
| `S_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击关闭 |
| `S_HasExpeditionReturn_*` | OCR "经验" | 关闭远征归来弹窗 |
| `S_IsGameIcon` | TemplateMatch `游戏图标.png`（全屏） | 点击重进 |
| `S_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `S_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `S_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `S_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `S_IsTroopRecordPage` | TemplateMatch `部队记录页面.png`（ROI `[577,8,130,35]`，阈值 0.95）| 点击退回 |
| `S_FallbackWait` | DoNothing | 兜底等待 |

## 卡死重启

```json
"S_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["S_DetectWhereAmI"]
}
```

枢纽超时 → `on_error` 触发 → `mumu-cli.exe control --vmindex <n> restart` 重启实例 → `am force-stop` 杀游戏 → `monkey` 重拉 → 回枢纽继续。需全局设置中开启"卡死重启"，默认不启用。

## on_error 覆盖

- 入口 `Sortie`、`S_ReturnHome`、`S_CheckAccel`、`S_IsHome` 无需
- 主枢纽子节点 `on_error → S_DetectWhereAmI`
- 主枢纽自身 `on_error → S_RestartGame`
- 路由节点（`S_PostSortieHub`、`S_PostClickMenuHub`、`S_CaptainHub`、`S_DetectAfterSortieNow` 等）`on_error → S_DetectWhereAmI`
- 所有识别节点 `on_error → S_DetectWhereAmI`
