# 合战场（Sortie）任务设计

## 概述

- 流水线文件：`resource/base/pipeline/Sortie.json`
- 入口节点：`Sortie`
- 主枢纽：`S_DetectWhereAmI`
- 节点前缀：`S_`
- 总节点数：172

## 主枢纽 `S_DetectWhereAmI`

25 个检测节点，超时 120s，`on_error → S_RestartGame`：

```json
"S_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["S_RestartGame"],
    "next": [
        "S_IsAnnouncementPopup", "S_IsLoginReward",
        "S_HasExpeditionReturn_Exp", "S_IsMarching",
        "S_IsBattleResult_Exp", "S_IsSwordDropColor",
        "S_IsKebiishi", "S_IsFormationSelect",
        "S_IsSwordSelect", "S_IsTeamSelect",
        "S_IsEraSelect", "S_IsRegionSelect",
        "S_IsSortieActivity", "S_IsMenuDirectory",
        "S_IsTeamStatusPanel", "S_CheckHomeBrightness",
        "S_IsRepair", "S_IsStopOnDamage",
        "S_IsGameIcon", "S_IsLoginButton",
        "S_IsGameUpdatePopup", "S_IsInGameUpdatePopup",
        "S_IsInternalReport",
```

## 主流程

### 出阵准备

```
本丸 → S_CheckHomeBrightness（`next: ["S_IsHome", "S_DetectWhereAmI"]`）→ S_IsHome → S_NavigateToSortie → S_ClickMenu
  → S_PostClickMenuHub → S_VerifyMenuSortie / S_CheckNavDirForRetry / S_DetectWhereAmI
    → S_ClickSortieInMenu（OCR "出阵"）→ S_VerifyMenuClosed → S_TryClickSortie
```

### 时代/地域/部队选择

`S_IsEraSelect` → `S_ClickEra` → `S_ConfirmEra`（时代选择）。`S_IsRegionSelect` → `S_VerifyRegionSelect` → `S_ClickRegion`（地域选择）。`S_IsTeamSelect` → `S_ClickTeam`（部队选择，由 GUI 选项覆盖 target 坐标）。

### 刀装补充

`S_CheckEquipmentPopup` TemplateMatch `整备刀装.png` → `S_PreCheckTroopRecord` → `S_PreCheckUseRecord` → `S_PreCheckClickRecordN` → `S_PreCheckUseRecordBtn`。

### 换队长

`S_CaptainHub` → `S_DragCaptain`（Custom 拖拽）/ `S_IsPreSortieConfirm` → `S_ClickSortieNow`。

### 行军循环

```
S_PostSortieHub
  ├─ 重伤检测（S_IsPreDamage1/2, S_StopOnDamagePopup/Text）
  ├─ 刀装弹窗（S_CheckEquipmentPopup）
  └─ S_DetectAfterSortieNow
       ├─ S_IsTroopDepleted（刀装破损）
       ├─ S_IsMarching → S_CheckBossBeforeMarch
       │    ├─ S_IsMarchingDamage（行军中重伤）
       │    ├─ Boss 检测（S_Boss_E2~8_R* × 40+ 节点）
       │    ├─ MidRetreat 节点（道中撤退）
       │    └─ S_PostClickMarching
       ├─ S_IsFormationSelect → 阵形选择
       ├─ S_FallbackWait
       └─ S_DetectWhereAmI
```

`S_CheckBossBeforeMarch` 路由 41 个检测节点，covering 所有时代王点和道中撤退场景。

### 重伤处理

| 模式 | 节点链 | 说明 |
|------|--------|------|
| 修刀 | `S_IsPreDamage1/2` → `S_LogPreDamage*` → `S_IsRepair` → `S_ClickRepair` → `S_ConfirmRepair` | 修刀后 `S_ReturnHome` → `S_ClickHomeInMenu` → 回本丸 |
| 停止 | `S_StopOnDamagePopup/Text` → `S_LogStopOnDamage*` | 弹窗检测，停止任务 |
| 行军重伤 | `S_IsMarchingDamage` → `S_LogMarchingDamage` → `S_ReturnHomeAfterMarchDamage` → `S_ConfirmReturnHome` → `S_ReturnHome` | 行军中检测到重伤立即撤退 |

`S_ConfirmReturnHome` TemplateMatch `合战场_确认返回本丸.png`（ROI `[564,305,152,33]`，阈值 0.9）。

### 王点撤退

`S_ClickRetreat` → `S_ConfirmRetreat`（OCR "确认返回本丸"）→ `S_ReturnHome`。

### 回到本丸

```
S_ReturnHome → S_ClickMenuFromRepair（OCR "目"）→ S_ClickHomeInMenu（点击 [1037,169,110,44]）→ 回本丸
或：S_ClickMenuStop → S_ClickHomeStop → S_ClickHomeFallback
```

`S_ClickHomeMenu` 使用 TemplateMatch `目录.png`，`S_CheckNavDirForRetry` OCR "目"（ROI `[1183,18,87,40]`）兜底重试。

## 导航链路

`S_ClickMenu` OCR "目" → `S_PostClickMenuHub` → `S_VerifyMenuSortie` / `S_CheckNavDirForRetry` / `S_DetectWhereAmI`。

`S_ClickSortieInMenu` OCR "出阵" → `S_VerifyMenuClosed`（TemplateMatch 菜单目录.png）→ `S_TryClickSortie` → `S_ClickSortieInMenu` 重试 / `S_DetectWhereAmI` 兜底。

## 重启游戏

```json
"S_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["S_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽 next 列表中节点不设 on_error
- 主枢纽 `on_error → S_RestartGame`
- `Sortie`（入口）、`S_ReturnHome`、`S_CheckAccel`、`S_IsHome` 无需（审核通过）
- `S_DetectSortOrder`、`S_DecideDamage_Pre`、`S_CaptainHub`、`S_TryClickRepair`、`S_PostSortieHub`、`S_PostClickMenuHub`、`S_SelectDamagedSword` 等路由节点已配置 `on_error → S_DetectWhereAmI` 或专用路由
- `S_ClickDescending`、`S_ConfirmSortAsc`、`S_ClickRepairDone`、`S_ClickMenuFromRepair`、`S_ClickMenu` 等识别节点已配置 `on_error → S_DetectWhereAmI`
- `S_TryClickRepair → S_SelectDamagedSword` on_error 指向 `S_CheckRepairScreen`（修复流程路由）

## 设计要点

- **部队记录页面防御**：`S_IsTroopRecordPage` 防止误触卡死
- **目录识别**：使用 OCR "目" 点击目录按钮
- **行军后子枢纽**：`S_DetectAfterSortieNow` 集中处理行军中的弹窗和状态变化
- **重伤三段处理**：出战前（修刀/停止）、行军中（撤退）、确定出阵前，全覆盖
- **Boss/MidRetreat 路由**：`S_CheckBossBeforeMarch` 41 节点覆盖所有时代，无需逐个加 on_error
- **刀装修复链路**：通过 `interface.json` 修刀选项启用整条 `S_ClickRepair` → `S_ConfirmRepair` → `S_ClickMenuFromRepair`
- **同步远征**：`S_IsHome.next` override 为 `["Expedition"]`
