# 合战场（Sortie）任务设计

## 概述

- 流水线文件：`resource/base/pipeline/Sortie.json`
- 入口节点：`Sortie`
- 节点前缀：`S_`
- 总节点数：约 160

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 重伤处理 | select | 修刀/停止，出阵前或行军中检测到重伤后的处理方式 |
| 选择部队 | select | 部队一~四 |
| 选择时代 | select | 1~8 时代 |
| 选择地域 | select | 1~4 地域 |
| 选择阵形 | select | 默认鱼鳞，可按需调整 |
| 换队长 | 复选框 | 通过筛选装备马的刀剑来切换队长 |
| 补充刀装 | 复选框 | 出阵前检测刀装不足弹窗并自动补充 |
| 王点前撤退 | 复选框 | 行军至王点前自动撤退，覆盖 E2-E8 共 27 图 |
| 道中撤退 | 复选框 | 需同时开启王点前撤退，含 E6/E8 道中节点 |
| 同步远征 | 复选框 | 回本丸后自动检查并派遣远征 |

## 时代/地域选择

`S_IsEraSelect` 无双重验证，直接进点击链路：

```json
"S_IsEraSelect": {
    "recognition": {
        "type": "TemplateMatch",
        "param": {
            "roi": [564, 54, 157, 54],
            "template": "时代选择.png",
            "green_mask": true,
            "threshold": [0.98]
        }
    },
    "next": ["S_ClickEra"]
}
```

`S_IsRegionSelect` 采用双重验证。主识别命中后先经 `S_VerifyRegionSelect` 复核，验证失败时 `next` 兜底直接跳回 `S_DetectWhereAmI` 重检测（不再等超时）。`on_error` 作为最后防线保留：

```json
"S_IsRegionSelect": {
    "recognition": {
        "type": "TemplateMatch",
        "param": {
            "roi": [558, 55, 169, 54],
            "template": "地域选择.png",
            "green_mask": true,
            "threshold": [0.98]
        }
    },
    "next": ["S_VerifyRegionSelect", "S_DetectWhereAmI"],
    "on_error": ["S_DetectWhereAmI"]
}
```

`S_VerifyRegionSelect` 与 `S_IsRegionSelect` 使用相同模板和 ROI 进行复核，命中后进入 `S_ClickRegion` 点击具体地域。

```json
"S_VerifyRegionSelect": {
```

## 重伤处理

重伤处理分两个阶段：**出战前**（`S_PostSortieHub` 中检测）和**行军中**（`S_CheckBossBeforeMarch` 中检测）。根据 GUI 选项「重伤处理」决定走修刀链路还是停止链路。

## 实现变更记录

| 变更 | 说明 |
|------|------|
| E2 ColorMatch→TemplateMatch | 6 个节点全部改造，消除颜色匹配导致的跨图误匹配 |
| E2-E8 ROI 全面重校 | 27 个地图所有 ROI 经实机验证重新校准 |
| 新增 E2_R3_3 | 2-3 第三 ROI，补充ColorMatch时缺失的检测点 |
| 新增 E5_R4_2 | 5-4 第二 ROI |
| 新增 E7_R4 | 7-4 此前完全缺失，现补全 |
| 新增 E6/E8 道中 | `S_MidRetreat_E6_R1`, `S_MidRetreat_E8_R1~R4`，需同时勾选王点前撤退 |
| E7 节点拆分 | E7_R2 → R2_1/R2_2, E7_R3 → R3_1/R3_2，双 ROI 覆盖 |
| E5 节点拆分 | E5_R4 → R4_1/R4_2 |
| green_mask 标记 | E7/E8 全部节点加入 green_mask，适配时代七/八背景色 |
| Verify 节点兜底 | `S_IsRegionSelect`、`S_VerifyMenuClosed`、`S_VerifyHomeMenuClosed`、`S_VerifyAfterRepairMenuClosed` 的 `next` 追加 `S_DetectWhereAmI`，验证失败立刻跳回检测循环 |
| 重伤处理文档补全 | 补充 `S_IsPreDamage1/2`、`S_StopOnDamagePopup/Text`、`S_IsMarchingDamage2`、`S_DecideDamage_Pre` 等节点，重构为出战前/行军中/停止模式三段结构 |
| S_ConfirmRetreat 新增 on_error | 添加 `"on_error": ["S_DetectWhereAmI"]`，OCR 识别"确认返回本丸"失败超时后跳回检测循环，避免任务直接失败 |
