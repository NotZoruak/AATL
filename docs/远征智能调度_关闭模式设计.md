# 远征智能调度 — 关闭模式设计（v3）

> **状态：已完成**（2026-07-25）

## 核心思路

**智能调度关闭时不启计时器。** 合战场依赖 `E_CheckTimerExpired`（计时器未启动 → `IsExpired()` 始终 true → 每次回本丸自然进 Expedition 检查）。陆联直接把 `LR_IsTeamSelect.next` 剥离，关闭时不走 `E_CheckTimerExpired`，永不触发 `E_GoHome`。

## 需求

| 任务类型 | 智能调度开启 | 智能调度关闭 |
|---------|-----------|-----------|
| 合战场 | 计时器 + 智能等待决定检查时机 | 每次回本丸直接检查队伍状况，无计时 |
| 活动（陆联/地下城等） | 计时器到期后主动回本丸检查 | 不做计时，不主动中途回本丸 |

## 改动

### 1. ExpeditionTimerAction.cs

`ExpeditionTimerAction.Run()`：`IsSmartSchedulingEnabled()` 为 false 时跳过 `StartTimer` 和"倒计时开始"日志，只关面板。

```
mode=reset? → ResetTimer → return
if (智能调度开启) {
    ScanAndStore → 设智能间隔 → 关面板
    StartTimer(intervalSeconds)
    日志("倒计时开始")
} else {
    关面板
}
```

### 2. interface.json — LR_同步远征（L3083–3087）

移除 `LR_IsTeamSelect.next: E_CheckTimerExpired`：入口不再绑定计时器。

### 3. interface.json — 智能调度开启

新增 `LR_IsTeamSelect.next: E_CheckTimerExpired`，为陆联注入计时链路。

### 不改的部分

- **S_同步远征**：全保留（`S_IsHome.next`、`E_AllTeamsBusy.next`、`E_TimerStart` 等不动）
- **智能调度关闭 case**：空 override，无需添加任何项
- **`E_TrackerOCR`**：留给独立远征，不受影响
- **`E_CheckTimerExpired`**：在 LR_同步远征中保留（next/on_error 任务特定值），由智能调度开启注入的 `LR_IsTeamSelect` 入口引用

## 预期行为

### 独立远征

| | 关闭 | 开启 |
|---|---|---|
| 派发后 | E_AllTeamsBusy 默认关闭面板 → E_GoHome → E_WaitRefresh 固定等待 | E_AllTeamsBusy → E_TrackerOCR OCR 扫描 → E_SmartWait 动态等待 |
| 计时器 | 无，E_WaitRefresh 固定延迟 | SmartWaitAction 取 min(最早归队, 间隔) |

> 独立远征走 `E_TrackerOCR` 路径，不经过 `E_TimerStart`，不受本次改动影响。

### 合战场 + 同步远征

| | 关闭 | 开启 |
|---|---|---|
| 回本丸后 | S_IsHome → E_CheckTimerExpired → 计时器未启动，IsExpired() 始终 true → 每次进 Expedition 检查 | S_IsHome → E_CheckTimerExpired → 计时器控制频率 → 到期才进 Expedition |
| 全忙时 | E_AllTeamsBusy → E_TimerStart → [关闭分支] 只关面板 → S_NavigateToSortie | E_AllTeamsBusy → E_TimerStart → [开启分支] OCR 扫描 + 启计时 → S_NavigateToSortie |
| 派发后 | E_LogDispatch → E_GoHome → 目录导航 → 回本丸 → 下一轮循环 | 同左 |
| 计时器 | 无 | ExpeditionTimerAction 内部启计时 + SmartWait 动态等待 |

### 陆联 + 同步远征

| | 关闭 | 开启 |
|---|---|---|
| 选队时 | LR_IsTeamSelect 走默认 next → 直接继续活动，不经过 E_CheckTimerExpired | LR_IsTeamSelect → E_CheckTimerExpired → 计时器控制是否回本丸 |
| 回本丸时 | LR_IsHome → Expedition 自然检查 | 同左 |
| 计时器 | 无 | 有 |

所有场景均无计时器：合战场每次回本丸自然检查，陆联选队时不再主动回本丸，独立远征走默认 `E_WaitRefresh` 固定延时。
