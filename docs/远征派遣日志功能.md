# 远征派遣日志输出功能

## 目标

在远征队伍被确认派出后输出日志，记录派出的队伍编号和目标地图。

## 涉及流水线

- **远征（Expedition.json）** — 独立远征任务
- **同步远征** — 合战场/地下城的 `S_同步远征`/`U_同步远征` 选项，共用 Expedition.json 节点

## 实现方案

### 新增自定义动作

创建 `resource/base/custom/DispatchLogAction.cs`，支持两种模式：

| 模式 | 参数 | 行为 |
|---|---|---|
| `mark` | `team: N` | 将队伍编号存入静态变量，返回 true |
| `log` | 无 | 读静态变量中的队伍编号 → 读实例配置文件获取该队伍地图 → 输出日志，清空静态变量 |

地图信息读取与 `ExpeditionMapSelectAction` 一致，从 `InstancesDirectory` 下的实例配置中获取该队伍在远征任务中的选项 index，映射为 `E-R` 格式。

### 节点改动

在每条队伍路径的 `E_SelectTeamBtn` 后插入 mark 节点，在 `E_ConfirmExpedition`（确认派出）后插入统一 log 节点：

```
部队1: E_SelectTeamBtn1 → E_MarkTeam1(mark, team=1) → E_StartExpedition
部队2: E_SelectTeamBtn2 → E_MarkTeam2(mark, team=2) → E_StartExpedition
部队3: E_SelectTeamBtn3 → E_MarkTeam3(mark, team=3) → E_StartExpedition
部队4: E_SelectTeamBtn4 → E_MarkTeam4(mark, team=4) → E_StartExpedition
部队5: E_SelectTeamBtn5 → E_MarkTeam5(mark, team=5) → E_StartExpedition

公共: E_StartExpedition → E_VerifyConfirmPopup → E_ConfirmExpedition → E_LogDispatch(log) → E_GoHome
```

改动量：5 个 `next` 链修改 + 6 个新增节点 + 1 个 `next` 链修改（E_ConfirmExpedition）。

同步远征的 pipeline_override 不改动 `E_SelectTeamBtn` 和 `E_ConfirmExpedition`，因此两种触发方式均自动生效。

### 日志格式

| 场景 | 输出 |
|---|---|
| 部队一派出至 4-1 | `[远征派遣] 部队一已派出远征至 4-1` |
| 部队三派出至 2-3 | `[远征派遣] 部队三已派出远征至 2-3` |
| 未标记队伍（异常） | `[远征派遣] 派出远征队伍` |

## 不涉及的流水线

重伤检测日志功能独立，与此功能无关。
