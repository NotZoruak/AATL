# 习合（Mix）任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/Mix.json`
- 入口节点：`Mix`
- 主枢纽：`M_DetectWhereAmI`
- 节点前缀：`M_`

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 搓糖 | switch | Yes 时检查乱舞等级，跳过已满级刀剑 |
| 刀种筛选 | switch | Yes 时按刀种筛选习合，默认开启 |

搓糖开启时启用 `M_CheckSubLevel` + `M_CheckLevel1~6`，禁用 `M_ClickMixDirect1~6`。刀种筛选开启时启用 `M_FilterSword1~7`（与刀解共用）。

## 主枢纽 `M_DetectWhereAmI`

20 个检测节点，`timeout: 120000`，`on_error → M_RestartGame`。

```json
"M_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["M_RestartGame"],
    "next": [
        "M_IsAnnouncementPopup", "M_IsTrainingLetter",
        "M_IsLoginReward", "M_DetectEmptyMailbox",
        "M_HasExpeditionReturn_Exp", "M_HasExpeditionReturn_Title",
        "M_CheckHomeBrightness", "M_DetectMenu",
        "M_DetectRefine", "M_DetectMix",
        "M_DetectMixSub", "M_DetectFilter",
        "M_DetectPurchasePopup", "M_DetectMailbox",
        "M_IsInternalReport", "M_IsGameIcon",
        "M_IsLoginButton", "M_IsGameUpdatePopup",
        "M_IsInGameUpdatePopup", "M_FallbackWait"
    ]
}
```

## 主流程链路

```
M_DetectWhereAmI（枢纽）
   ├── 本丸 → M_CheckHomeBrightness → M_DetectHome
   │     → M_DetectMenu（菜单目录）
   │
   ├── 合成页 → M_DetectRefine → M_DetectMix
   │     → M_HideUnmixable（隐藏无法习合的刀剑）
   │       → M_DetectMixSub（显示保护中的刀剑男士）
   │
   ├── 筛选（可选）→ M_DetectFilter → M_FilterSwordHub
   │     → M_FilterConfirm → M_FilterPostHub → M_PostFilterMix
   │
   ├── 习合循环 → M_CheckSubLevel / M_ClickSelectAll
   │     → M_CheckAndMix（蓝色按钮）
   │       → M_ConfirmMix1 → M_ConfirmMix2 → 循环
   │
   ├── 格子检查（6 格）→ M_CheckPos1~6
   │     ├── M_DetectEmptyN（空格→去邮箱）
   │     ├── M_DetectLockedN（锁定）
   │     ├── M_CheckLevelN（搓糖：等级检查）
   │     └── M_ClickMixDirectN（直接习合，搓糖时禁用）
   │
   ├── 邮箱 → M_DetectMailbox → M_PostFilterReward
   │     → M_DetectPurchase → M_MailboxCloseFinal
   │
   └── 闪退恢复 / 弹窗关闭 / M_FallbackWait
```

## 搓糖机制

开启时：每格习合前 OCR 读取乱舞等级，已达上限跳过。`M_DetectLockedN` 的 on_error 改为 `M_CheckLevelN`。无材料时 `M_ExitNoMaterial` → 回枢纽。

## 闪退恢复

| 节点 | 识别 | 动作 |
|------|------|------|
| `M_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `M_IsTrainingLetter` | TemplateMatch `修行书信.png` | 自循环关闭 |
| `M_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击关闭 |
| `M_DetectEmptyMailbox` | TemplateMatch `空邮箱.png` | 回枢纽 |
| `M_IsGameIcon` | TemplateMatch `游戏图标.png` | 点击重进 |
| `M_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `M_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `M_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `M_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `M_FallbackWait` | DoNothing | 兜底等待 |

## 重启游戏

```json
"M_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["M_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → M_DetectWhereAmI`
- 主枢纽自身 `on_error → M_RestartGame`

## 设计要点

- **刀种共享**：筛选节点与刀解共用（`M_FilterSwordN` 和 `D_FilterSwordN` 同启同停）
- **搓糖**：OCR 读取乱舞等级，已满跳过，避免浪费素材
- **6 格轮询**：`M_CheckPosN` 路由判断空格/锁定/可习合/已满级
- **邮箱链**：新刀剑进邮箱 → 收取 → 继续习合
