# 刷花任务设计

## 概述

- 流水线文件：`resource/base/pipeline/FlowerBrush.json`
- 入口节点：`FlowerBrush`
- 节点前缀：`FB_`
- 总节点数：约 55
- 无双枢纽架构：主枢纽 `FB_DetectWhereAmI` + 行军后子枢纽 `FB_DetectAfterMarching`

## GUI 选项

无 GUI 选项。任务固定使用部队一单骑出阵 1-1，阵形逆行阵。

```json
{
    "name": "刷花",
    "entry": "FlowerBrush",
    "default_check": false,
    "repeatable": true,
    "repeat_count": 1,
    "label": "刷花",
    "description": "仅支持部队一单骑出阵1-1刷花，请提前解散部队一并为且仅为需要刷花的刀剑男士装备马匹和刀装"
}
```

## 主流程链路

```
FB_DetectWhereAmI（枢纽）
    │
    ├── FB_CheckHomeBrightness → FB_IsHome → FB_NavigateToSortie
    │     └── FB_ClickMenuForSortie（OCR "目录"）→ FB_VerifyMenuOpened
    │           └── FB_ClickSortieInMenu（OCR "出阵"）→ FB_VerifySortieMenuClosed
    │
    ├── FB_IsSortieActivity → FB_ClickBattlefieldTab（切回合战场标签）
    │
    ├── FB_IsTeamSelect → FB_ClickTeam1 → FB_ClickCaptainSlot
    │     └── 固定选部队一，点击队长槽进入刀剑选择
    │
    ├── FB_IsEraSelect → FB_SelectEra → FB_ClickFirstEra → FB_ClickEraConfirm
    │     └── 固定选时代一 [246, 389]
    │
    ├── FB_IsRegionSelect → FB_SelectRegion → FB_ClickRegion1_1
    │     └── 固定选 1-1 地域 [225, 344]
    │
    ├── FB_IsFormationSelect → FB_SelectFormation
    │     └── FB_ClickFormation1 → FB_ClickFormation2（双击逆行阵 [1017, 421]）
    │
    ├── FB_IsSwordSelect（行军后回枢纽时触发）
    │     └── FB_ClickFilter → FB_ClearResidualFilter → FB_FilterByTroop
    │           → FB_FilterBySakura → FB_ConfirmFilter
    │           → FB_DetectSortOrder → FB_ClickDescending / FB_ConfirmSortAsc
    │           → FB_CaptainFind / FB_CaptainSwipe → FB_ClickSortieNow
    │
    ├── FB_IsMarching → FB_DetectAfterMarching（进入行军后子枢纽）
    │
    └── 闪退恢复 / 弹窗关闭（下方详述）
```

## 行军后子枢纽 `FB_DetectAfterMarching`

行军中点击后进入子枢纽，处理行军途中的结果弹窗和阵形选择：

```json
"FB_DetectAfterMarching": {
    "next": [
        "FB_PostExpeditionReturn_Exp",
        "FB_PostExpeditionReturn_Title",
        "FB_PostMarching",
        "FB_PostBattleResult_Exp",
        "FB_PostSwordDropColor",
        "FB_PostFormationSelect",
        "FB_CheckPostHomeBright",
        "FB_IsGameIcon",
        "FB_IsLoginButton",
        "FB_PostFallbackWait"
    ]
}
```

子枢纽自循环：处理完弹窗后回到 `FB_DetectAfterMarching` 继续检测，直到行军结束回到本丸 → `FB_PostHome`（本丸检测）后回到主枢纽。

行军按钮持续点击：`FB_PostMarching` TemplateMatch "行军" → 点击 → 回子枢纽。

## 刀剑筛选链路

刷花核心流程——通过刀装和樱吹雪状态筛选需控花的刀剑：

```
FB_IsSwordSelect（OCR "刀剑男士选择"）
    │
    └── FB_ClickFilter（点击筛选按钮 [828, 82, 68, 25]，post_delay: 800）
          │
          └── FB_ClearResidualFilter（清除残留筛选 [752, 137, 97, 29]，post_delay: 800）
                │
                └── FB_FilterByTroop（按装备筛选 [226, 514, 109, 26]，post_delay: 800）
                      │
                      └── FB_FilterBySakura（按樱吹雪筛选 [965, 438, 91, 34]，post_delay: 800）
                            │
                            └── FB_ConfirmFilter（确认筛选 [592, 603, 107, 46]）
                                  │
                                  └── FB_DetectSortOrder
                                        ├── FB_ClickDescending（OCR "降序" → 点击降序）
                                        └── FB_ConfirmSortAsc（OCR "升序"，仅识别无动作）
                                              │
                                              ├── FB_CaptainFind（ColorMatch 找空闲刀剑 → 点击 → FB_ClickSortieNow）
                                              └── FB_CaptainSwipe（滑动页面 → 回到 FB_CaptainFind）
```

五个筛选点击依次为：打开筛选页面 → 取消残留筛选 → 勾选刀装 → 勾选樱吹雪 → 确认筛选。

## 闪退恢复节点

| 节点 | 类型 | 行为 |
|------|------|------|
| `FB_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭，`timeout: 3000` |
| `FB_IsLoginReward` + `FB_LoginRewardClick2` + `FB_LoginRewardClick3` | TemplateMatch + Click×2 | 三击关闭，`timeout: 3000` |
| `FB_HasExpeditionReturn_Exp` | OCR "经验" | 点击关闭 |
| `FB_HasExpeditionReturn_Title` | OCR "远征结果" | 点击关闭 |
| `FB_IsBattleResult_Exp` | OCR "经验" | 点击关闭 |
| `FB_IsSwordDropColor` | ColorMatch | 点击行军按钮继续 |
| `FB_IsInternalReport` | TemplateMatch `内番报告.png` | 点击关闭 |
| `FB_IsGameIcon` | TemplateMatch 全屏 | 点击重进，`post_delay: 3000` |
| `FB_IsLoginButton` | TemplateMatch `登录.png` | 点击登录，`post_delay: 3000` |
| `FB_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭商店更新弹窗，`post_delay: 2000` |
| `FB_IsInGameUpdatePopup` | OCR "更新" | 关闭游戏内更新弹窗，`post_delay: 2000` |
| `FB_FallbackWait` | DoNothing | 回 `FB_DetectWhereAmI` |

## 设计要点

- **无选项硬编码**：部队一、时代一、1-1 地域、逆行阵均硬编码在流水线中，无 GUI 配置
- **双枢纽架构**：主枢纽处理页面级状态（本丸/菜单/刀剑选择等），子枢纽处理行军中途弹窗（战斗结果/阵形/远征归来/刀剑掉落），各司其职避免 hub 膨胀
- **刀装+樱吹雪筛选**：依次点击筛选→清残留→刀装→樱吹雪→确认，仅选中装备刀装且无樱吹雪的刀剑（需控花对象）
- **升序后颜色匹配找队长**：确认升序排列后，ColorMatch 检测空闲刀剑位置并点击，无空闲时滑动翻页，选中后点击即刻出阵
- **自循环**：子枢纽通过 `FB_PostMarching` 持续点击行军按钮直到战斗结束回到本丸，`FB_PostHome` 检测本丸后回到主枢纽重新出发
