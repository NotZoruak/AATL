# 刷花任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/FlowerBrush.json`
- 入口节点：`FlowerBrush`
- 节点前缀：`FB_`
- 总节点数：71
- 双枢纽架构：主枢纽 `FB_DetectWhereAmI`（21 节点）+ 行军后子枢纽 `FB_DetectAfterMarching`（10 节点）

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| FB_选择部队 | select | 部队一 ～ 五，默认部队一 |

```json
{
    "name": "刷花",
    "entry": "FlowerBrush",
    "default_check": false,
    "repeatable": true,
    "repeat_count": 1,

}
```

## 主流程链路

```
FB_DetectWhereAmI（枢纽）
    ├── 本丸检测 → FB_IsHome → FB_NavigateToSortie
    │     → FB_ClickMenuForSortie（OCR "目"）
    │       → FB_VerifyMenuOpened → FB_VerifyLeftMenuSortie
    │         → FB_ClickSortieInMenu（OCR "出阵"）
    │           → FB_VerifySortieMenuClosed → FB_TryClickSortie
    │
    ├── 活动标签 → FB_ClickBattlefieldTab（切回合战场）
    │
    ├── 部队选择 → FB_IsTeamSelect → FB_ClickTeam
    │     → FB_Dissolve（解散 2-6 号位）→ FB_ClickCaptainSlot
    │
    ├── 时代/地域 → 固定选时代一 + 1-1
    │
    ├── 阵形选择 → 固定逆行阵
    │
    ├── 刀剑筛选（行军后触发）
    │     → 筛选 → 排序 → ColorMatch 找队长 → 即刻出阵
    │
    ├── 行军 → FB_DetectAfterMarching（子枢纽）
    │
    └── 闪退恢复 / 弹窗关闭
```

## 部队与解散

`FB_ClickTeam` 由 GUI 选项「FB_选择部队」控制点击坐标（部队一~五）。默认部队一 `[154,93]`。

```json
"FB_ClickTeam": {
    "action": { "type": "Click", "param": { "target": [154, 93, 1, 1] } },
    "next": ["FB_Dissolve"],
    "pre_delay": 100
}
```

### 解散 2-6 号位

`FB_Dissolve` 路由到两个分支：`FB_DissolveCheck`（ColorMatch 解散）和 `FB_ClickCaptainSlot`（点击队长槽）。

```json
"FB_Dissolve": {
    "next": ["FB_DissolveCheck", "FB_ClickCaptainSlot"]
}
```

```json
"FB_DissolveCheck": {
    "recognition": { "type": "ColorMatch", "param": { "roi": [1075, 211, 36, 420], "upper": [46, 46, 46], "lower": [40, 40, 40], "method": 4, "count": 1 } },
    "action": "Click",
    "next": ["FB_Dissolve"]
}
```

`FB_DissolveCheck` 灰度检测未使用槽位并点击叉掉，自循环直到 2-6 号位全部清空，仅剩 1 号位（原队长）。然后走 `FB_ClickCaptainSlot` 进入换队长。

```json
"FB_ClickCaptainSlot": {
    "action": { "type": "Click", "param": { "target": [1024, 140, 30, 50] } },
    "next": ["FB_DetectWhereAmI"],
    "pre_delay": 100
}
```

## 行军后子枢纽 `FB_DetectAfterMarching`

处理行军途中的结果弹窗和阵形选择：

```json
"FB_DetectAfterMarching": {
    "on_error": ["FB_DetectWhereAmI"],
    "next": [
        "FB_PostExpeditionReturn_Exp", "FB_PostExpeditionReturn_Title",
        "FB_PostMarching", "FB_PostBattleResult_Exp",
        "FB_PostSwordDropColor", "FB_PostFormationSelect",
        "FB_CheckPostHomeBright",
        "FB_IsGameIcon", "FB_IsLoginButton",
        "FB_PostFallbackWait"
    ]
}
```

`FB_PostMarching` TemplateMatch 行军按钮 → 持续点击直到战斗结束。回到本丸后经 `FB_CheckPostHomeBright → FB_PostHome`（TemplateMatch `本丸.png`，任务终点），任务 `repeatable: true` 自动从入口重启。

## 刀剑筛选链路

```
FB_IsSwordSelect（OCR "刀剑男士选择"）
  → FB_ClickFilter（筛选按钮 [828,82,68,25]）
    → FB_ClearResidualFilter（清残留 [752,137,97,29]）
      → FB_FilterByTroop（刀装 [226,514,109,26]）
        → FB_FilterBySakura（樱吹雪 [965,438,91,34]）
          → FB_ConfirmFilter（确认 [592,603,107,46]）
            → FB_DetectSortOrder
              ├─ FB_ClickDescending（OCR "降序"→点击）
              └─ FB_ConfirmSortAsc（OCR "升序"→仅识别）
                    ├─ FB_CaptainFind（ColorMatch 找空闲→点击→出阵）
                    └─ FB_CaptainSwipe（滑动翻页→回 FB_CaptainFind）
```

### 排序与出阵

```json
"FB_DetectSortOrder": {
    "on_error": ["FB_DetectWhereAmI"],
    "next": ["FB_ClickDescending", "FB_ConfirmSortAsc"]
}
```

`FB_ClickDescending` OCR "降序" 点击切换，`FB_ConfirmSortAsc` OCR "升序" 确认已升序排列。

```json
"FB_CaptainFind": {
    "recognition": { "type": "ColorMatch", "param": { "roi": [1224, 137, 11, 553], "upper": [206, 108, 108], "lower": [200, 102, 102], "method": 4, "count": 1, "connected": true } },
    "action": "Click",
    "next": ["FB_ClickSortieNow"],
    "pre_delay": 100
}
```

ColorMatch 空闲刀剑（粉色标记）→ 点击选中 → `FB_ClickSortieNow` OCR "即刻" → 点击出阵。

## 重启游戏

```json
"FB_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["FB_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → FB_DetectWhereAmI`
- 主枢纽 `on_error → FB_RestartGame`
- `FlowerBrush`（入口）、`FB_DetectSortOrder`、`FB_ClickSortieNow`、`FB_IsHome`、`FB_DetectAfterMarching` → `FB_DetectWhereAmI`
- `FB_PostHome` 无 next，任务 `repeatable: true` 自动重启

## 设计要点

- **可选部队**：`FB_ClickTeam` 由 FB_选择部队 override 控制目标坐标
- **解散清位**：`FB_DissolveCheck` ColorMatch 灰度检测自动叉掉 2-6 号位，无需手动操作
- **双枢纽**：主枢纽处理页面级状态，子枢纽处理行军中途弹窗
- **刀装+樱吹雪**：筛选仅选中装备刀装且无樱吹雪的刀剑（需控花对象）
- **升序+ColorMatch**：确认升序后用 ColorMatch 找空闲刀剑，无空闲时滑动翻页
- **自循环行军**：子枢纽持续点击行军直到战斗结束
