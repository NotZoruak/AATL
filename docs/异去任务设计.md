# 异去任务设计

## 概述

- 游戏 2026-08-12 更新新增「异去」玩法，原合战场玩法改称「过去」
- 异去与过去流程几乎一致：时代/地域/部队选择、同步远征、刀装/疲劳/重伤处理
- 差异点：
  1. 时代选择界面有「过去/异去」两个切换按钮，异去 tab 下的时代/地域选择页面识别特征与过去不同（布局相同，视觉不同）
  2. 异去没有王点前撤退和道中撤退（43 个 Boss/MidRetreat 节点默认禁用，一路打到底）
  3. 异去有门票机制：出阵时确认使用门票，不足时弹窗提示
- 方案：异去整合进合战场任务（GUI 选项切换），pipeline 差异全部通过选项 override 表达，不复制节点

## GUI 选项设计

### 任务选项列表（调整后）

```
["过去/异去", "S_选择时代", "S_选择地域", "S_选择部队", "S_选择阵形",
 "S_重伤处理", "S_刀装破坏处理", "S_疲劳处理", "S_换队长", "S_同步远征"]
```

「S_王点前撤退」「S_道中撤退」从顶层移入「过去」case 的子选项。

### 「过去/异去」选项（select，置顶）

```json
"过去/异去": {
  "name": "过去/异去",
  "label": "过去/异去",
  "type": "select",
  "default_case": "过去",
  "cases": [
    {
      "name": "过去",
      "DisplayName": "过去",
      "option": ["S_王点前撤退", "S_道中撤退"]
    },
    {
      "name": "异去",
      "DisplayName": "异去",
      "pipeline_override": { ...见下... },
      "option": ["异去_重复次数", "异去_不购买门票"]
    }
  ]
}
```

- 「过去」：无 pipeline_override（现有行为即过去模式），子选项为王点前撤退/道中撤退
- 「异去」：pipeline_override 见「异去模式 override」，子选项为重复次数输入框与不购买门票

### 子选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 异去_重复次数 | input(int) | 默认 -1。任务启动时读取该值覆写任务重复次数；过去模式强制 -1 无限 |
| 异去_不购买门票 | checkbox | 照搬陆联/战术训练语义：勾选 = 门票不足时终止任务；不勾选 = 不足时自动补充后继续 |

## Pipeline 设计

### 更名

`S_IsEraSelect` → `S_IsPastEraSelect`（仅更名，识别/next/on_error 全部不变：TemplateMatch 时代选择.png，ROI [104,331,49,235]，next [S_ClickEra]）。副枢纽 `SF_IsEraSelect` 保持原名。

`S_IsRegionSelect` → `S_IsPastRegionSelect`（仅更名，识别/next/on_error 全部不变：TemplateMatch 地域选择.png，ROI [848,607,257,63]，next [S_VerifyEra, S_ClickBackToEra]）。

### 时代选择链路（两模式对称归位）

| 当前页面命中 | 过去模式（默认） | 异去模式 |
|------|------|------|
| 过去版 `S_IsPastEraSelect` | S_ClickEra 直接选时代（现状） | S_ClickIsekaiTab 点「异去」[945,77,61,30] → 回枢纽 |
| 异去版 `S_IsIsekaiEraSelect` | S_ClickPastTab 点「过去」[846,78,58,29] → 回枢纽 | S_ClickEra 选时代 |

无论游戏是否记忆 tab，两个模式都能自动归位。

### 地域选择链路（两模式对称归位）

| 当前页面命中 | 过去模式（默认） | 异去模式 |
|------|------|------|
| 过去版 `S_IsPastRegionSelect` | S_VerifyEra → 点地域（现状） | S_ClickBackToEra 返回重选 |
| 异去版 `S_IsIsekaiRegionSelect` | S_ClickBackToEra 返回重选 | S_VerifyEra → 点地域 |

### 时代验证

`S_VerifyEra` OCR ROI 过去版 [831,80,26,26]；异去模式 override 为 [836,80,27,26]（expected 仍由「S_选择时代」选项注入，不变）。副枢纽 `SF_VerifyEra` 不改。

### 异去模式 override（「异去」case 的 pipeline_override）

```json
{
  "S_IsPastEraSelect": { "next": ["S_ClickIsekaiTab"] },
  "S_IsIsekaiEraSelect": { "next": ["S_ClickEra"] },
  "S_IsPastRegionSelect": { "next": ["S_ClickBackToEra"] },
  "S_IsIsekaiRegionSelect": { "next": ["S_VerifyEra", "S_ClickBackToEra"] },
  "S_VerifyEra": { "recognition": { "param": { "roi": [836, 80, 27, 26] } } },
  "S_IsIsekaiTicketConfirm": { "enabled": true },
  "S_IsIsekaiNoTicket": { "enabled": true }
}
```

### 「异去_不购买门票」override（checkbox）

```json
"异去_不购买门票": {
  "type": "checkbox",
  "cases": [
    {
      "name": "",
      "pipeline_override": {
        "S_IsIsekaiNoTicket": {
          "action": { "type": "Click", "param": { "target": [1028, 38, 25, 26] } },
          "next": []
        }
      }
    }
  ]
}
```

勾选后 `S_IsIsekaiNoTicket` 改为点关闭 [1028,38,25,26]，空 next 终止任务；未勾选保持默认（点补充 → 确认购买 → 回主枢纽）。

### 行军链路

异去不提供王点前撤退/道中撤退选项，43 个 Boss/MidRetreat 节点保持默认禁用，`S_CheckBoss` 路由只剩 `S_PostClickMarching` 兜底前进 → 一路打到底。

### 一轮结束与循环接续

异去打完后回到**地域选择页面**（不是本丸），中间有数秒到十几秒的过渡画面。

- `S_IsIsekaiBattleEnd`（TemplateMatch 异去结算.png，ROI [610,331,52,26]，阈值 0.8）挂主枢纽检测链常驻：一轮结束的标志画面命中 → `S_IsIsekaiRegionEnd`
- `S_IsIsekaiRegionEnd`（TemplateMatch 地域选择_异去.png，ROI [833,617,152,41]，阈值 0.98）识别到异去地域选择页面（过渡画面结束、回到地域选择页）→ **无 next，本轮任务结束**（job 完成）——以「真正回到页面」替代固定 freeze 等待，动画长短自适应
- 队列层由 `MFATask.Count`（「异去_重复次数」联动）控制轮数：每轮任务启动 → 打完 → 结算标志 → 回地域选择页确认 → 任务结束 → 队列跑下一轮，共 N 轮
- 下一轮启动后，结算画面由 `S_IsBattleResult_Exp`/`S_IsBattleResult_Title` 点掉，过渡画面期间 `S_IsIsekaiRegionEnd` 轮询等待，地域选择页面出现后命中结束；随后 `S_IsIsekaiRegionSelect` 接管选地域续跑
- 过去模式无此结束点（pipeline 自循环无限挂机），行为不变

### 门票处理

门票确认弹窗出现在点击「即刻出阵」后。`S_IsIsekaiTicketConfirm` 挂入 `S_PostSortieHub.next`，位于 `S_CheckEquipmentPopup` 之后（默认 disabled，异去模式启用）：

```
S_PostSortieHub.next = [S_IsPreDamage1, S_StopOnDamagePopup, S_IsPreDamage2, S_StopOnDamageText,
                        S_CheckEquipmentPopup, S_IsIsekaiTicketConfirm, S_DetectAfterSortieNow]

S_IsIsekaiTicketConfirm(OCR [597,54,82,38]「出阵」)
  → 点确认 [565,578,151,48] → freeze 300ms
    → S_IsIsekaiNoTicket(OCR [532,59,221,35]「归城提灯一补充」)
        ├─ 勾选「异去_不购买门票」→ 点关闭 [1028,38,25,26] → freeze → 空 next 终止
        └─ 默认 → 点补充 [582,593,113,40] → freeze
            → S_IsIsekaiConfirmPurchase(OCR [600,58,78,36]「确认」→ 点 [729,581,101,43] → freeze)
                → 回主枢纽重新出阵
```

## C# 代码改动

`MaaProcessor.CreateNodeAndParam` 重复次数联动：

- 「过去/异去」选项为「异去」（Index == 1）时，从**「过去/异去」选项的 SubOptions** 中读取「异去_重复次数」的 `data.repeat_count` 值覆写 Count——该输入项是「异去」case 的子选项，**不在顶层 Option 列表里**（实测踩坑：从顶层找永远为 null，回退 -1 导致只跑 1 轮）
- 选「过去」时强制 -1（pipeline 自循环即无限），避免残留轮数配置影响过去模式
- Count 三元表达式增加 `repeatCount == -1` 直通分支：`-1` 直接传给 MFATask（Run 中转为 int.MaxValue 无限），否则 `Repeatable = false` 时会被折成单次
- 异去每轮打完由 `S_IsIsekaiBattleEnd` 结束任务，队列按 Count 循环 N 轮；过去模式无此结束点，行为不变

## 兼容性说明

- 「S_王点前撤退」「S_道中撤退」从顶层移入子选项后，现有配置中这两个选项的勾选状态会丢失（回到默认未勾选），发布公告需说明
- 过去模式行为完全不变（无 override 生效、repeat_count 强制 -1）

## 实测验证（2026-08-12 通过）

| 项目 | 结论 |
|------|------|
| 异去全流程 | 切 tab 归位、选时代地域（1-4）、出阵、行军一路打到底，正常 |
| 门票处理 | 确认使用门票弹窗正常点掉 |
| 重复次数 | 设为 2 跑两轮后停止；-1 无限；「过去」模式不受残留配置影响 |
| 结算动画 | `S_IsIsekaiBattleEnd` 命中后 3s freeze，无多次命中问题 |
| 一轮结束 | 打完回地域选择页面，队列按 Count 循环接续，正常 |
