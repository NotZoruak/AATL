# 回到本丸（GoHome）任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/GoHome.json`
- 入口节点：`GoHome`
- 主枢纽：`G_DetectWhereAmI`
- 节点前缀：`G_`
- 无 GUI 选项，作为独立工具（一键回城）存在

## 主枢纽 `G_DetectWhereAmI`

14 个检测节点，`timeout: 120000`，`on_error → G_RestartGame`。

```json
"G_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["G_RestartGame"],
    "next": [
        "G_IsAnnouncementPopup", "G_IsTrainingLetter",
        "G_IsLoginReward", "G_IsCloseablePage",
        "G_IsHome", "G_IsGameIcon",
        "G_IsLoginButton", "G_IsGameUpdatePopup",
        "G_IsInGameUpdatePopup", "G_IsInternalReport",
        "G_VerifyMenuDir", "G_IsMenuDirectory",
        "G_LeaveTroopRecord", "G_FallbackWait"
    ]
}
```

## 主流程链路

```
G_DetectWhereAmI（枢纽）
   ├── 菜单目录 → G_IsMenuDirectory（OCR "目"）
   │     → G_VerifyMenuDir（TemplateMatch 菜单目录.png）
   │       → G_ClickBackToHome（点击"回到本丸" [1037,169,110,44]）
   │         → 回枢纽
   │
   ├── 关闭页面 → G_IsCloseablePage（检测 × 号）
   │     → G_ClickDirectoryTop（pre_delay 3000 后点"目"）
   │       → G_VerifyMenuDir → G_ClickBackToHome
   │
   ├── 本丸 → G_IsHome（TemplateMatch "本丸.png"）
   │     → DoNothing（任务完成）
   │
   ├── 部队记录 → G_LeaveTroopRecord
   │     → 点击退回 → 回枢纽
   │
   └── 闪退恢复 / 弹窗关闭 / G_FallbackWait
```

## 设计说明

本 pipeline 不注册为任务列表项，作为"一键回城"独立工具。用途：任务卡住时手动触发，从任意界面强制回到本丸。

核心逻辑：尝试识别菜单目录 → 点击"回到本丸"按钮；如果当前是关闭型页面（弹窗等），先点 × 号关闭 → 再走菜单路径；识别到本丸即完成。

## 闪退恢复

| 节点 | 识别 | 动作 |
|------|------|------|
| `G_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `G_IsTrainingLetter` | TemplateMatch `修行书信.png` | 自循环关闭 |
| `G_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击关闭 |
| `G_IsGameIcon` | TemplateMatch `游戏图标.png` | 点击重进 |
| `G_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `G_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `G_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `G_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `G_FallbackWait` | DoNothing | 兜底等待 |

## 重启游戏

```json
"G_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["G_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → G_DetectWhereAmI`
- 主枢纽自身 `on_error → G_RestartGame`
