# 刀解（Disassemble）任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/Disassemble.json`
- 入口节点：`Disassemble`
- 主枢纽：`D_DetectWhereAmI`
- 节点前缀：`D_`

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 短刀～薙刀 | checkbox ×7 | 勾选的刀种参与筛选解体，默认全不选 |

```json
{
    "name": "刀解",
    "entry": "Disassemble",
    "default_check": false,
    "repeatable": true,
    "option": ["短", "胁", "打", "太", "大太", "枪", "薙"]
}
```

每个刀种勾选后通过 pipeline_override 启用对应 `D_FilterSword1~7`（同时启用习合的 `M_FilterSword1~7`）。

## 主枢纽 `D_DetectWhereAmI`

19 个检测节点，`timeout: 120000`，`on_error → D_RestartGame`。

```json
"D_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["D_RestartGame"],
    "next": [
        "D_IsAnnouncementPopup", "D_IsTrainingLetter",
        "D_IsLoginReward", "D_DetectEmptyMailbox",
        "D_HasExpeditionReturn_Exp", "D_HasExpeditionReturn_Title",
        "D_CheckHomeBrightness", "D_DetectMenu",
        "D_DetectForge", "D_DetectDisassemble",
        "D_DetectFilter", "D_DetectPurchasePopup",
        "D_DetectMailbox", "D_IsInternalReport",
        "D_IsGameIcon", "D_IsLoginButton",
        "D_IsGameUpdatePopup", "D_IsInGameUpdatePopup",
        "D_FallbackWait"
    ]
}
```

## 主流程链路

```
D_DetectWhereAmI（枢纽）
   ├── 本丸 → D_CheckHomeBrightness → D_DetectHome
   │     → D_DetectMenu（菜单目录）
   │
   ├── 锻造页 → D_DetectForge → D_DetectDisassemble
   │     → D_DetectFilter（筛选）
   │       → D_FilterSwordHub → D_FilterConfirm
   │         → D_FilterPostHub（timeout 5000）
   │
   ├── 解体 → D_PostFilterDisassemble（刀解选择，post 1000/2000）
   │     → D_DisassembleCheckConfirm（勾选框）
   │       → D_DisassembleClickFinal（刀解确认）
   │         → 循环回 D_PostFilterDisassemble
   │
   ├── 邮箱 → D_DisassembleGoToMailbox → D_DisassembleVerifyMenu
   │     → D_DetectMailbox（收件箱）
   │       → D_PostFilterMailbox → D_DetectReward
   │         → D_DetectPurchasePopup → D_MailboxCloseFinal
   │           → D_MailboxCloseVerify
   │
   ├── 奖励 → D_PostFilterReward → D_DetectReward
   │     → D_DetectPurchase → D_MailboxCloseFinal
   │
   └── 闪退恢复 / 弹窗关闭 / D_FallbackWait
```

## 筛选与解体

`D_FilterSword1~7` 各对应一个刀种按钮，由选项启用。`D_FilterPostHub` timeout 5000 → 所有刀种勾选完成后 → `D_PostFilterDisassemble`（点击"刀解"）→ `D_DisassembleCheckConfirm`（勾选复选框）→ `D_DisassembleClickFinal`（最终解体确认）→ 自循环回 `D_PostFilterDisassemble` 继续解体剩余刀剑。

无剩余刀剑时：`D_DisassembleGoToMailbox` → `D_DisassembleVerifyMenu` → 回枢纽 → 走邮箱链收取新刀剑 → 再解体。

## 闪退恢复

| 节点 | 识别 | 动作 |
|------|------|------|
| `D_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `D_IsTrainingLetter` | TemplateMatch `修行书信.png` | 自循环关闭 |
| `D_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击关闭 |
| `D_DetectEmptyMailbox` | TemplateMatch `空邮箱.png` | 回枢纽 |
| `D_IsGameIcon` | TemplateMatch `游戏图标.png` | 点击重进 |
| `D_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `D_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `D_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `D_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `D_FallbackWait` | DoNothing | 兜底等待 |

## 重启游戏

```json
"D_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["D_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → D_DetectWhereAmI`
- 主枢纽自身 `on_error → D_RestartGame`
- `D_FilterPostHub` 内邮箱/奖励链 on_error → `D_FilterPostHub`（重试）

## 设计要点

- **刀种共享**：筛选节点与习合共用（`D_FilterSwordN` 和 `M_FilterSwordN` 同启同停）
- **解体循环**：`D_PostFilterDisassemble` → `D_DisassembleCheckConfirm` → `D_DisassembleClickFinal` → 自循环直到无刀可解
- **邮箱自动收取**：解体后的刀剑进邮箱 → `D_DetectMailbox` 链收取 → 继续解体
