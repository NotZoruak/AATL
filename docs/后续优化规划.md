### 远征任务整合为「后勤」

将当前独立运行的远征任务扩展为综合后勤系统，统一管理游戏内周期性资源操作。

**任务重命名**：`远征` → `后勤`（label 改为"后勤"，name 保持 `Expedition` 兼容 pipeline）

**核心优化：智能调度**

`E_WaitRefresh` 是回本丸后的页面加载缓冲 + 重检测间隔。当前 `post_delay` 硬编码为 60000（60 秒），GUI 的「刷新间隔」输入框（`RefreshInterval`，默认 10 分钟）实际未被任何代码使用——用户改了也没效果。同步远征（合战场/地下城勾选）走 `S_IsHome → Expedition`，不使用 `E_WaitRefresh`。

目标：派遣远征时 OCR 各部队剩余时间，取最早归队时刻 + 1 分钟缓冲；与用户设置的间隔取较小值动态设置 `post_delay`。

实现方式：

- 新增自定义动作 `ExpeditionTimeTracker`：派完后 OCR 五个部队面板，解析"空闲"或"剩余 HH:MM:SS"，计算最早归队时间戳，存入 `ConfigurationManager`
- `post_delay = min(最早归队 + 60s, 用户设置间隔 × 60s)`
- 同步远征：`Expedition` 入口前加判断节点，读最早归队时间戳，未到期则 `DoNothing → 回主任务`
- 空闲部队时时间戳为 0，用户间隔 × 60s 兜底
- **先修 bug**：`RefreshInterval` 选项当前无效，需为其添加 `pipeline_override` 以实际控制 `E_WaitRefresh.post_delay`

**新增功能模块**：

- [ ] OCR 剩余时间解析（`ExpeditionTimeTracker` 自定义动作）
- [ ] 动态 post_delay 替代固定 60s
- [ ] 同步远征跳过未到期检测
- [ ] 内番自动安排
- [ ] 景趣收获

### 全局设置标签页

删除高级标签页，在任务设置卡片中改为两个标签：`[常规] [全局]`。

**机制**：
- `global_option` 中的选项全局共享，不属于任何单个任务
- 从任意任务点「全局」进入同一个面板
- `IsCommon` / `IsGlobal` 二者互斥
- 新增 `GlobalOptionSettings` StackPanel，由 `TaskOptionGenerator.GenerateGlobalPanelContent` 渲染

**预设全局选项**：

| 选项 | 类型 | 说明 |
|------|------|------|
| 换队长筛选方式 | select / checkbox 组 | 装备马 / 樱吹雪 / 刀装 等筛选条件，替换各任务中分散的换队长逻辑 |
| 游戏区服 | select | 选择当前使用的游戏服务器，影响截图识别区域和模板匹配 |
| 卡死最大等待时间 | input（int） | 枢纽 `timeout` 值（秒），替代当前硬编码的 120000ms |

**改动范围**：
- `TaskQueueViewModel`：新增 `IsGlobal` 属性
- `TaskQueueView.axaml`：两个 ToggleButton + `GlobalOptionSettings` 面板
- `TaskOptionGenerator`：新增 `GenerateGlobalPanelContent`
- `interface.json`：`global_option` 数组 + 对应选项定义
- 删除 `AdvancedOptionSettings` 相关代码

### 日志输出优化

1. **任务完成日志带名称**：当前输出"任务完成"，改为输出"{任务名} 任务完成"（如"陆联 任务完成"）
2. **队列汇总日志**：所有任务执行完毕后（无论成功/失败/手动停止），输出一行总结：`累计 X 成功，Y 失败`

**实现**：在 `MaaProcessor` 任务执行循环中累计成功/失败计数，队列结束时输出汇总。
