### 远征智能调度（全局开关）

全局 switch 选项，默认关闭。开启后远征派遣完成时 OCR 各部队面板的剩余时间，动态计算下次检查时机，替代固定间隔轮询。

**当前状态**：`E_WaitRefresh.post_delay` 由 `RefreshInterval` 全局选项的 `pipeline_override` 动态设置（已完成），但值是用户手动填的固定秒数。

**目标**：派遣远征后自动 OCR 五个部队状态面板，解析"空闲"或"剩余 HH:MM:SS"，取最早归队时刻作为下次唤醒时间。

**实现方式**：

- 新增自定义动作 `ExpeditionTimeTracker`（`mode: "start"`）：派完后 OCR 部队面板，解析剩余时间，存入 `ConfigurationManager` 作为最早归队时间戳
- `E_WaitRefresh.post_delay` 动态计算：`min(最早归队, RefreshInterval × 60s)`，空闲部队时时间戳为 0，走 RefreshInterval 兜底
- 同步远征：`Expedition` 入口前加判断节点，读最早归队时间戳，未到期则跳过远征检查直接回主任务
- 全局选项 `远征智能调度`（switch，默认关闭）：开启后启用 `ExpeditionTimeTracker` + 动态间隔逻辑；关闭时回退到固定 `RefreshInterval` 间隔

**配置项**：

| 选项 | 类型 | 说明 |
|------|------|------|
| 远征智能调度 | switch | 全局开关，默认关闭 |



### 队内拖拽换队长

`换队长方式` 全局选项的第三模式。当前已有马匹筛选和刀装筛选（通过 `pipeline_override` 改 ClickCaptain3 坐标）。

**需求**：选中队内拖拽后，不走 `ClickCaptainSlot` 节点，改为自定义动作 `DragCaptainAction`：
1. OCR 六个位置的疲劳值，找最低值所在位置
2. 最低值在位置 2-6 → 长按（`LongPress`）该位置 500ms → `Swipe` 拖到队长槽（位置 1）
3. 最低值已在位置 1 → 跳过拖拽，继续后续流程

**子选项**：`拖拽跳过位置`（checkbox 多选，共 6 个位置）

队内拖拽时 OCR 六个位置的疲劳值，排除用户勾选的"跳过位置"后取最低值所在位置。被跳过的位置不参与比较，始终保留原位。

**实现**：
- `interface.json`：
  - 队内拖拽 case 加 `"option": ["拖拽跳过位置"]`
  - 新增 `拖拽跳过位置` checkbox 选项（6 个 case：位置一~六）
- `DragCaptainAction`：
  1. OCR 六个位置的疲劳值
  2. 排除用户勾选的跳过位置
  3. 取疲劳最低的位置作为拖拽源
  4. 拖拽目标：跳过位置含"位置一"时拖到位置二，否则拖到位置一
  5. 长按（`LongPress` 500ms）+ `Swipe` 拖拽
- `pipeline_override`：禁用 `ClickCaptainSlot`，启用 `DragCaptainAction` + `next → IsPreSortieConfirm`
- 6 个位置 ROI（待补充实机坐标）

### 掉落刀剑识别

出阵结算时 OCR 识别掉落刀剑名称，记录到日志/GUI 面板，用于追踪锻刀/掉落收集进度。

**要点**：

- 识别时机：出阵后结算画面的掉落展示环节
- 识别方式：OCR 刀剑男士名称（需要排除已持有/重复标识的干扰）
- 数据落点：写入日志 + GUI 面板展示历史掉落列表
- 后续可扩展：与锻刀公式表联动，标记已收集/未收集

**难点**：结算画面结构复杂（多个掉落同时展示、大成功/两倍经验等特殊状态），ROI 需要动态适配。

### 远征前疲劳检查 + 自动刷花

派遣远征前检查部队刀剑疲劳值，若低于用户自定义阈值则自动跳转刷花任务，刷满后再继续远征派遣。

**流程**：

```
E_CheckTeamN（OCR 判断待机）
    ↓ 命中
E_CheckFatigueN（OCR 部队各位置疲劳值）
    ├── 全部 ≥ 阈值 → 继续远征派遣
    └── 有低于阈值 → E_TriggerFlowerBrush（记录目标部队 + 跳转刷花）
        ↓
    FlowerBrush 刷花完成 → 返回 E_ExpSubHubN 重新检测
```

**配置项**：

| 选项 | 类型 | 说明 |
|------|------|------|
| 疲劳阈值 | input（int） | 默认 40，低于此值的刀剑触发刷花 |
| 刷花地图 | select | 刷花使用的合战场地图，默认 1-1 |

**关键问题**：

- 疲劳值 OCR 识别：位置 ROI 与 DragCaptainAction 中的 `FatigueRois` 复用，格式为 `XX/100`
- 部队切换：刷花需要该部队处于待机且可出阵状态，远征派遣前是天然时机
- 循环终止：刷花后需重新检查疲劳，避免刷花失败导致无限循环
- 与同步远征的交互：同步远征模式下刷花完成后应回到原任务而非远征枢纽
