## 待讨论

### 远征任务整合为「后勤」

将当前独立运行的远征任务扩展为综合后勤系统，统一管理游戏内周期性资源操作。

**任务重命名**：`远征` → `后勤`（label 改为"后勤"，name 保持 `Expedition` 兼容 pipeline）

**核心优化：智能调度**

现状：独立远征任务用 `E_WaitRefresh`（固定 60s）；同步远征（合战场/地下城勾选）通过 `S_IsHome → Expedition` 每轮回本丸触发。两路径都不智能。

目标：派遣远征时 OCR 每个部队剩余时间，记录最早归队时刻；后续回本丸时判断是否到期，未到期跳过。

实现方式：

- 新增自定义动作 `ExpeditionTimeTracker`：
  - 派完后 OCR 五个部队面板，解析"空闲"或"剩余 HH:MM:SS"
  - 计算最早归队 Unix 时间戳 + 1 分钟缓冲，存入 `ConfigurationManager`
- 独立远征路径：`E_WaitRefresh.post_delay` 读取最早归队时间动态设置
- 同步远征路径：`Expedition` 入口前加判断节点，读配置中最早归队时间，未到期则 `DoNothing → 回主任务`
- 有空闲部队时记录时间戳为 0，下次回本丸必定触发检查

**新增功能模块**：

- [ ] OCR 剩余时间解析（`ExpeditionTimeTracker` 自定义动作）
- [ ] 动态 post_delay 替代固定 60s
- [ ] 同步远征跳过未到期检测
- [ ] 内番自动安排
- [ ] 景趣收获
