# 任务选项配置说明

记录 `interface.json` 中任务选项（option）的配置形式，以及 MFAAvalonia 任务设置面板对各类型的渲染规则。渲染逻辑源码位于 `_src/MFAAvalonia/Helper/TaskOptionGenerator.cs`。

## 术语对照

| 层面 | 正式名称 | 说明 |
|------|----------|------|
| 协议层 | ProjectInterface 协议 | `interface.json` 遵循的 MaaFramework 官方协议 |
| 协议层 | 任务（Task） | `task` 数组中的条目 |
| 协议层 | 选项（Option）/ 配置项 | `option` 字典中的条目，源码注释称「配置项」 |
| 协议层 | 选项分支（Case） | 选项下 `cases` 数组中的条目 |
| 协议层 | 高级选项（Advanced Option） | 顶层 `advanced` 字典中的条目 |
| 代码层 | 任务选项面板 | `TaskOptionGenerator` 生成的设置区块 UI |
| UI 层 | Avalonia 控件 | 实际渲染的 ComboBox、ToggleSwitch 等，样式来自 SukiUI |

## 选项类型总览

选项的 `type` 字段共四个取值：`select`（默认，可省略）、`input`、`switch`、`checkbox`。渲染分发逻辑见 `TaskOptionGenerator.AddOption`：

| interface type | 渲染控件 | 变体说明 |
|----------------|----------|----------|
| `select`（默认） | ComboBox | 两条 case 且名为 `yes`/`no` 时自动映射为 ToggleSwitch |
| `switch` | ToggleSwitch | 开关滑块，右侧放置 |
| `checkbox` | CheckBox | 方框+✓+右侧文字，与任务列表勾选框共用 GlassCard 模板，多 case 自适应换行 |
| `input` + `int`/`float`/`string` | TextBox | 带正则校验和水印提示 |
| `input` + `bool` | ToggleSwitch | 输入字段中的布尔项也渲染为开关 |

## 各类型详细说明

### select（下拉框，默认类型）

不写 `type` 字段、含 `cases` 数组和字符串 `default_case` 的选项渲染为下拉框。

```json
"S_重伤处理": {
  "label": "重伤处理",
  "default_case": "修刀",
  "cases": [
    { "name": "修刀", "pipeline_override": { "...": {} } },
    { "name": "停止", "pipeline_override": { "...": {} } }
  ]
}
```

渲染细节：

- 布局为两列 Grid：`[图标 + 标签 + 说明图标 | ComboBox]`，标签在控件左侧
- ComboBox 搜索已关闭（`SetCanSearch = false`），失焦时禁用键盘导航
- 特例：恰好两条 case 且 `name` 分别为 `yes` / `no`（不区分大小写）时，自动渲染为 ToggleSwitch 而非下拉框（`MFAExtensions.ShouldSwitchButton`）

MATR 当前使用：部队一～五远征地图、`S_重伤处理`、`S_选择部队`、`S_选择时代`、`S_选择地域`、`S_选择阵形`、`LR_选择部队`、`LR_选择难度` 等。

### switch（开关滑块）

显式声明 `"type": "switch"`，配合两条 case 使用。布局为三列 Grid：`[图标 + 标签 + 说明图标 | 伸缩空白 | ToggleSwitch]`，滑块靠右。打开对应 yes case，关闭对应 no case。

MATR 当前未使用此类型。

### checkbox（复选框）

声明 `"type": "checkbox"`。渲染为 Avalonia `CheckBox` 控件，样式与任务列表的启用勾选框共用 SukiUI 的 GlassCard 模板（`CheckBoxStyles.axaml`），视觉上为方框 + ✓ + 右侧文字。原实现曾使用 `ToggleButton` 内嵌文字，后于 2026-07-17 改为 `CheckBox`。

```json
"S_换队长": {
  "label": "换队长",
  "type": "checkbox",
  "cases": [
    { "name": "", "pipeline_override": { "...": {} } }
  ],
  "default_case": []
}
```

渲染细节（`TaskOptionGenerator.CreateCheckboxControl`）：

- 单 case：`CheckBox`（`Content` 绑选项 `label`），方框在左、文字在右；若选项带 `description`，下方追加问号提示图标
- 多 case：外部先渲染选项 `label` 作为组标题，各 case 生成独立 `CheckBox`（`Content` 绑 case 名称）排入 `WrapPanel` 自适应换行，首次布局后统一等宽
- 面板生成时，任务选项列表中连续出现的多个 checkbox 会被收集进同一区域并排摆放（`AddOptionsWithCheckboxGrid`）
- 勾选状态记录在 `SelectedCases` 列表中，`default_case` 用数组表示默认勾选的 case 名
- 样式与任务列表勾选框共用 SukiUI `CheckBoxStyles.axaml` 中的 GlassCard 模板，方框 20×20、圆角 6，勾选后 GlassCard 变主色、白色 ✓ 浮现

MATR 当前使用：`S_换队长`、`S_补充刀装`、`S_王点前撤退`、`S_道中撤退`、`S_同步远征`、`LR_换队长`、`LR_部队交替`、刀种筛选（短/胁/打/太/大太/枪/薙）、`搓糖`、`不筛选` 等。

### input（输入框）

声明 `"type": "input"`，通过 `inputs` 数组定义一个或多个输入字段，每个字段的 `pipeline_type` 决定控件形式。

```json
"RefreshInterval": {
  "label": "刷新间隔（分钟）",
  "type": "input",
  "inputs": [
    {
      "name": "minutes",
      "label": "间隔（分钟）",
      "default": "10",
      "pipeline_type": "int",
      "description": "设置过短可能导致游戏卡顿"
    }
  ]
}
```

渲染细节（`TaskOptionGenerator.CreateInputControl`）：

- `pipeline_type` 为 `int` / `float` / `string` → TextBox，两列 Grid `[标签 | TextBox]`，支持正则校验（`pattern`）与水印提示（`pattern_msg`）
- `pipeline_type` 为 `bool` → ToggleSwitch，三列 Grid `[标签 | 伸缩空白 | 滑块]`，值以 `"true"` / `"false"` 字符串写入
- 多个输入字段或选项带 `description` 时，上方额外渲染选项级标题
- 字段值通过 `{字段名}` 占位符注入选项级 `pipeline_override`

MATR 当前使用：`RefreshInterval`（int）、`LR_换队配置` 队伍序列（string）、`U_层数选择`（int，预留）。

### advanced（高级选项）

顶层 `advanced` 字典定义，渲染为 AutoCompleteBox（自动完成框），`default` 数组作为补全候选列表。布局为两列 Grid `[标签 | AutoCompleteBox]`。

MATR 当前未使用此区块。

## 任务级内置控件

除选项控件外，每个任务条目自身有两种内置设置：

| 字段 | 控件 | 说明 |
|------|------|------|
| `default_check` | 任务启用勾选 | 控制任务默认是否勾选进队列 |
| `repeatable` / `repeat_count` | 重复次数数字框 | `repeatable: true` 时显示，MATR 中陆联、刷花启用 |

## 通用规则

- 选项标签取 `label`（或 `DisplayName`），缺失时回退到选项 `name`
- 选项可声明 `controller` / `resource` 字段限定适用范围，不匹配当前控制器或资源包时整个控件隐藏（`IsOptionApplicable`）
- `option` 字典中未被任何任务 `option` 列表引用的定义不会出现在 GUI 中（MATR 中的 `U_*`、`难度选择` 等即为预留定义）

## 子选项与齿轮导航

选项的 `cases` 中可通过 `"option": ["子选项名"]` 声明子选项。含子选项的控件标签右侧会显示 16×16 齿轮图标（`FluentIcon.Settings`），点击齿轮进入子页面：

- 子页面与主选项视图互斥显示（类似常规/高级选项卡切换）
- 左上角返回按钮（`ArrowLeft` 图标 + 选项名称），点击回到主视图
- 子选项按所属 case 分组，每组以 case 名称作为标题
- 子选项渲染为完整的交互控件（复用 `AddSubOption` 逻辑，支持嵌套）

子页面导航状态由 `TaskQueueViewModel` 的三个属性驱动：

| 属性 | 类型 | 说明 |
|------|------|------|
| `IsSubPageOpen` | bool | 是否显示子页面 |
| `SubPageTitle` | string | 返回按钮旁显示的标题 |
| `SubPageContent` | Control | 子选项控件容器 |

> 注意：设有齿轮的选项，选中 case 后子选项**不会**在主页面内联展开（由 `HasSubOptions` 判断跳过 `UpdateSubOptions` 渲染），只能通过齿轮进入子页面查看。
