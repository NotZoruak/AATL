# 数据查找表 — 侧边栏功能

## 目标

在侧边栏新增"数据查找表"入口，提供多张游戏静态数据表的快速查阅和搜索。

## 实际实现（2026-06-28）

### 架构

单 View + 单 ViewModel，SukiUI TabControl 切换四个子页面，DataGrid 展示表格数据。

### 子页面及功能

| 页面 | 功能 | 交互 |
|---|---|---|
| 锻刀公式 | 刀剑锻造资源配方表 | ComboBox 刀种筛选 + TextBox 名称搜索，实时过滤 |
| 经验表 | 等级经验参考表 + 升级计算器 | NumericUpDown 输入当前经验和目标等级，Button 计算还需经验 |
| 地图收益 | 各地图资源点收益 | 纯静态 DataGrid |
| 远征收益 | 各远征地图收益 | 纯静态 DataGrid |

### 与原始设计的差异

- **删除刀装公式**：数据查找范围聚焦于锻刀和地图相关
- **经验表改为计算器**：不再做等级搜索，改为输入当前经验+目标等级计算还需经验
- **地图收益/远征收益无搜索**：数据量较小，静态展示即可
- **TabControl 替代 ToggleButton**：利用 SukiUI 内置 TabControl 主题，更简洁
- **单 ViewModel 架构**：四个子页面结构相似，拆分无必要

### 搜索/计算实现

**锻刀公式搜索**：
- `ForgeSearchCategoryIndex`（ComboBox 绑定）：全部 / 短刀 / 胁差 / 打刀 / 太刀 / 大太刀 / 枪 / 薙
- `ForgeSearchName`（TextBox 绑定）：按刀剑男士名称模糊匹配
- `[ObservableProperty]` 的 `partial void OnXxxChanged` 触发 LINQ 过滤，`Clear() + Add()` 重建展示集合

**经验计算器**：
- `CurrentExp`（当前经验值）、`TargetLevel`（目标等级 1-99）
- `[RelayCommand] CalculateExp()`：查找目标等级累计经验 - 当前经验 = 还需经验
- 下方始终展示完整经验表 DataGrid 供参考

## 远征收益页实现细节（2026-06-29）

### 真实数据
- 20 条远征数据，来源为游戏内截图逐行核对
- 列序：远征 / 时间 / 木炭 / 玉钢 / 冷却材 / 砥石 / 总资源 / 小判 / 加速符 / 委托符

### 效率计算
- 时长解析：m → /60，h → 直接取数值
- 效率 = 收益 / 小时
- 所有资源列（含加速符、委托符）都有效率值
- 格式：≥1 显示整数，<1 显示 2 位小数

### UI
- 格内双行：收益值 FontSize 16 + 效率 FontSize 12 灰色
- 行高 60px，全部列 DataGridTemplateColumn 统一布局（Border Padding 4,3）
- 列宽（固定像素）：远征 82 / 时间 105 / 资源×4 98 / 总资源 108 / 小判 105 / 加速符 105 / 委托符 105
- 行选中：SelectionMode="Single"，橙色边框

### 着色规则
- 每列独立计算最大效率值
- 效率 ≤ max × 0.3 → 透明无底色
- 效率 > 阈值 → 暖琥珀线性渐变（最浅 rgba(255,200,120,0.12) → 最深 rgba(255,140,30,0.45)）
- 值为 0 的格不上色
