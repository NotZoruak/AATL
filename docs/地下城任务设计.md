# 地下城（Underground）任务设计

## 概述

- 流水线文件：`assets/resource/base/pipeline/Underground.json`
- 入口节点：`Underground`
- 主枢纽：`U_DetectWhereAmI`
- 节点前缀：`U_`

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| U_层数选择 | select | 1-99 层，支持搜索，默认"不启用" |
| U_选择部队 | select | 部队一～五，默认部队一 |
| U_选择阵形 | select | 各阵形，默认逆行阵 |
| U_重伤处理 | select | 修刀并继续/修刀并停止/停止 |
| U_刀装破坏处理 | select | 停止/补充刀装/刀装保护/补充+刀装保护 |
| U_疲劳处理 | select | 无/停止/刷花 |
| U_换队长 | checkbox | 启用队长拖拽切换 |
| U_每轮回本丸 | checkbox | 每层完成回到本丸检查远征 |
| U_动画跳过 | checkbox | 把 FallbackWait 改为点击跳过动画 |
| U_同步远征 | checkbox | 回本丸后自动派遣远征 |

## 主枢纽 `U_DetectWhereAmI`

28 个检测节点，`timeout: 120000`，`on_error → U_RestartGame`。

```json
"U_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["U_RestartGame"],
    "next": [
        "U_IsAnnouncementPopup", "U_IsTrainingLetter",
        "U_IsLoginReward", "U_IsTutorial",
        "U_HasExpeditionReturn_Exp", "U_HasExpeditionReturn_Title",
        "U_IsMarching", "U_IsBattleResult_Exp",
        "U_IsBattleResult_Title", "U_IsSwordDropColor",
        "U_IsSpecialDrop", "U_IsFormationSelect",
        "U_IsSwordSelect", "U_IsTeamSelect",
        "U_IsSortie", "U_IsEventPage",
        "U_CheckHomeBrightness", "U_IsMenuDirectory",
        "U_IsRepair", "U_IsStopOnDamage",
        "U_IsGameIcon", "U_IsLoginButton",
```

## 主流程链路

```
U_DetectWhereAmI（枢纽）
   ├── 活动页 → U_IsEventPage（TemplateMatch "地下城.png"）
   │     → U_SelectFloor（DungeonFloorSelectAction）
   │       → U_EnterUnderground（点击出阵）
   │         → U_IsTeamSelect
   │
   ├── 部队选择 → U_IsTeamSelect
   │     → U_CheckEquipmentPopup / U_StopOnEquipmentPopup / U_ClickTeam
   │       → U_CaptainHub → U_DragCaptain / U_IsPreSortieConfirm
   │         → U_IsPreSortieConfirm（OCR "即刻"）→ U_ClickSortieNow
   │
   ├── 出阵确认 → U_PostSortieHub
   │     ├── U_ConfirmEnterUnderground（出阵确认弹窗）
   │     ├── U_IsPreDamage（重伤检测，模板识别）
   │     ├── U_StopOnDamagePopup（停止模式弹窗）
   │     ├── U_CheckEquipmentPopup（刀装补充）
   │     └── U_DetectAfterSortieNow
   │
   ├── 行军循环 → U_DetectAfterSortieNow
   │     → U_IsMarchingDamage → U_IsFormationSelect → U_IsMarching
   │       → U_CheckBeforeMarch → [重伤/疲劳/刀装/轮次检查]
   │         ├── U_IsMarchingDamage（重伤→撤退）
   │         ├── U_FatigueDetect（疲劳→回本丸）
   │         ├── U_EqCheck（刀装→回本丸）
   │         ├── U_CheckRoundComplete（轮次完成）
   │         │     → U_ContinueNextRound / U_GoHomeAfterRound
   │         └── U_ClickMarching（兜底前进）
   │
   ├── 重伤处理 → U_IsPreDamage
   │     ├── 修刀链 → U_NavigateToRepair → … → U_TryClickAfterRepair
   │     └── 停止 → U_StopOnDamagePopup → U_TerminateOnDamage
   │
   ├── 回本丸 → U_IsHome → U_NavigateToActivity
   │     → U_ClickMenu → U_PostClickMenuHub
   │       → U_ClickSortieInMenu → U_VerifyMenuClosed → U_TryClickSortie
   │
   └── 闪退恢复 / 弹窗关闭 / U_FallbackWait
```

## 楼层选择

`U_IsEventPage` TemplateMatch `Activity/地下城.png`，命中后直接进 `U_SelectFloor`。`U_SelectFloor` Custom `DungeonFloorSelectAction`，参数由 `U_层数选择` 注入（target_floor、十位/个位 ROI 及上下按钮坐标）。选「不启用」时跳过选层（override `U_IsEventPage.next` 直接到 `U_EnterUnderground`）。

## 行军循环

`U_IsMarching`（TemplateMatch `合战场_行军.png`）→ `U_CheckBeforeMarch`（路由）→ 按顺序：重伤 → 疲劳 → 刀装 → 轮次检查 → 兜底前进。

`U_CheckRoundComplete` OCR "传送凭证" → `U_ContinueNextRound`（继续行军，enabled 默认 true）/ `U_GoHomeAfterRound`（回本丸，enabled 默认 false，由 `U_每轮回本丸` 选项启用）。

## 闪退恢复

| 节点 | 识别 | 动作 |
|------|------|------|
| `U_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `U_IsTrainingLetter` | TemplateMatch `修行书信.png` | 自循环关闭 |
| `U_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击关闭 |
| `U_IsTutorial` | TemplateMatch `地下城教程.png` | 点击关闭 |
| `U_IsGameIcon` | TemplateMatch `游戏图标.png` | 点击重进 |
| `U_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `U_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `U_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `U_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `U_IsConnectionInterrupted` | OCR "连接中断" | 点击重连 |
| `U_LeaveTroopRecord` | TemplateMatch `部队记录页面.png` | 点击退回 |
| `U_FallbackWait` | DoNothing（动画跳过时改为点击 `[180,11,25,28]`） | 兜底等待 |

## 重启游戏

```json
"U_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["U_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → U_DetectWhereAmI`
- 主枢纽自身 `on_error → U_RestartGame`
- 修刀链节点 → `U_DetectWhereAmI` 或专用恢复路径（`U_CheckRepairScreen` / `U_LogNoDamagedSword`）

## 同步远征集成

勾选后 `U_IsHome.next` 改为 `["Expedition"]`（回本丸切远征管道）。`U_每轮回本丸` 启用后 `U_GoHomeAfterRound` 替代 `U_ContinueNextRound`。智能调度时 `U_CheckRoundComplete.next` 插入 `E_CheckTimerExpired`。

## 设计要点

- **楼层选择**：`DungeonFloorSelectAction` 十位/个位独立点击，支持 1-99 层。不启用时直接跳过进入出阵
- **行军扁平化**：`U_CheckBeforeMarch` 路由替代多层嵌套，重伤/疲劳/刀装/轮次串行检测
- **出阵确认**：`U_ConfirmEnterUnderground` 自循环到 `U_PostSortieHub`，直到弹窗消失
- **动画跳过**：`U_FallbackWait` 被 override 为点击跳过按钮，利用枢纽循环的每次 fallback 触发
- **连接中断**：`U_IsConnectionInterrupted` 专属节点，地下城活动特有的服务器中断弹窗
