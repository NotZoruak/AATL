# 地下城（Underground）任务设计

## 概述

- 流水线文件：`resource/base/pipeline/Underground.json`
- 入口节点：`Underground`
- 主枢纽：`U_DetectWhereAmI`
- 节点前缀：`U_`
- 总节点数：156

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| U_层数选择 | select（可搜索） | 不启用 / 1-99，默认不启用 |
| U_选择部队 | select | 部队一 ～ 部队五，默认部队一 |
| U_选择阵形 | select | 不启用 / 鱼鳞阵 / 横队阵 / 雁行阵 / 鹤翼阵 / 方阵 / 逆行阵，默认逆行阵 |
| U_重伤处理 | select | 修刀并继续 / 修刀并停止 / 停止，默认修刀并继续 |
| U_刀装破坏处理 | select | 停止 / 补充刀装 / 刀装保护 / 补充+刀装保护，默认补充刀装 |
| U_疲劳处理 | select | 无 / 停止 / 刷花，默认无 |

## 主枢纽 `U_DetectWhereAmI`

28 个检测节点，超时 120s，`on_error → U_RestartGame`：

```json
"U_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["U_RestartGame"],
    "next": [
        "U_IsAnnouncementPopup", "U_IsTrainingLetter",
        "U_IsLoginReward", "U_IsTutorial",
        "U_HasExpeditionReturn_Exp", "U_HasExpeditionReturn_Title",
        "U_IsMarching", "U_IsBattleResult_Exp",
        "U_IsBattleResult_Title", "U_IsSwordDropColor",
        "U_IsSpecialDrop", "U_IsFormationSelect",
        "U_IsSwordSelect", "U_IsTeamSelect",
        "U_IsSortie", "U_IsEventPage",
        "U_CheckHomeBrightness", "U_IsMenuDirectory",
        "U_IsRepair", "U_IsStopOnDamage",
        "U_IsGameIcon", "U_IsLoginButton",
        "U_IsGameUpdatePopup", "U_IsInGameUpdatePopup",
        "U_IsInternalReport", "U_IsConnectionInterrupted",
        "U_LeaveTroopRecord", "U_FallbackWait"
    ]
}
```

`U_LeaveTroopRecord` TemplateMatch `部队记录页面.png`（ROI `[577,8,130,35]`，阈值 0.95），命中后点击 `[63,28,17,17]` 返回枢纽。

地下城特有恢复节点：`U_IsTrainingLetter`（修行书信）、`U_IsTutorial`（地下城教程）、`U_IsSpecialDrop`（特殊掉落）、`U_IsConnectionInterrupted`（连接中断）。

## 主流程

### 进入地下城

```
本丸 → U_CheckHomeBrightness → U_IsHome → U_NavigateToUnderground → U_ClickMenu
  → U_PostClickMenuHub → U_VerifyMenuSortie / U_CheckNavDirForRetry / U_DetectWhereAmI
    → U_ClickSortieInMenu（OCR "出阵"）→ U_VerifyMenuClosed → U_TryClickSortie
      → U_IsEventPage → U_VerifyEventPage → U_SelectFloor / 直接进入
        → U_EnterUnderground → U_IsTeamSelect
```

`U_EnterUnderground` Click `[1141,614,120,49]` 确认进入。

### 层数选择（U_层数选择）

`U_SelectFloor` 为 Custom 节点（`DungeonFloorSelectAction`），由选项注入 `custom_action_param`：

| 模式 | 行为 |
|------|------|
| 不启用 | `U_VerifyEventPage.next` override 为 `[U_EnterUnderground, U_DetectWhereAmI]`，绕过 `U_SelectFloor` |
| 1-99 | select 下拉搜索，注入 `target_floor`、十位/个位 ROI（`[985,303,60,99]` / `[1053,303,60,99]`）与加减按钮坐标 |

### 部队/阵形选择

`U_IsTeamSelect` → `U_CheckEquipmentPopup` / `U_StopOnEquipmentPopup` / `U_ClickTeam`（target 由 U_选择部队 覆盖，默认部队一 `[154,93,1,1]`）。`U_IsFormationSelect` TemplateMatch `阵形选择.png` → `U_ClickFormation1/2`（target 由 U_选择阵形 覆盖，默认逆行阵 `[1017,421,1,1]`）。

### 刀装补充

`U_CheckEquipmentPopup` TemplateMatch `整备刀装.png` → `U_PreCheckTroopRecord` → `U_PreCheckUseRecord` → `U_PreCheckClickRecordN` → `U_PreCheckUseRecordBtn` → `U_PreConfirmSupply`。

### 换队长

`U_CaptainHub` → `U_ClickCaptainSlot` / `U_IsPreSortieConfirm` → `U_ClickSortieNow` → `U_PostSortieHub`。U_换队长 启用时走 `U_IsSwordSelect` → `U_DetectSortOrder` → `U_ClickCaptain1~5` → `U_DragCaptain`（Custom 拖拽换队长）。

### 行军检测架构

`U_IsMarching`（TemplateMatch `合战场_行军.png`）→ `U_CheckBeforeMarch.next` 平级化：

```
U_CheckBeforeMarch.next = [U_IsMarchingDamage, U_FatigueDetect, U_EqCheck, U_CheckRoundComplete, U_ClickMarching]
```

| 节点 | 识别 | 功能 |
|------|------|------|
| `U_IsMarchingDamage` | TemplateMatch `重伤.png`，ROI `[229,116,90,569]`，阈值 0.85 | 行军中重伤 → 点击 `[763,446,48,44]` → `U_LogMarchingDamage` |
| `U_FatigueDetect` | TemplateMatch `重疲劳.png`，ROI `[254,154,31,502]`，阈值 0.9 | 行军中重疲劳 → 点击 `[763,446,48,44]` |
| `U_EqCheck` | DirectHit 路由枢纽 | 刀装破坏检测，next 含 `U_EqCheckTemplate` + 18 个颜色匹配 + `U_CheckRoundComplete` + `U_ClickMarching` 兜底 |
| `U_CheckRoundComplete` | OCR "传送凭证"，ROI `[947,148,101,34]` | 层数完成 → `U_GoHomeAfterRound` / `U_ContinueNextRound` |
| `U_ClickMarching` | Click `[1067,558,120,79]` | 兜底前进 |

**刀装保护检测**：`U_EqCheckTemplate` TemplateMatch `刀装破坏.png`（ROI `[576,135,162,529]`，阈值 0.85）与 18 个 `U_EqCheckC_R*C*` ColorMatch 单像素点（6×3 网格：列 x `[591,650,708]`，行 y `[184,278,372,466,560,654]`，upper `[184,183,183]` / lower `[182,181,181]`）。

行军检测命中后均点击 `[763,446,48,44]`（"否"，关闭中断确认弹窗）→ `U_ReturnHomeAfterMarchDamage`（Click `[1208,449,1,1]`）→ `U_ConfirmReturnHome`（OCR "确认返回本丸"）→ 回本丸。

### 回合结算

`U_CheckRoundComplete` OCR "传送凭证" 判定本层完成：

| 节点 | 功能 |
|------|------|
| `U_GoHomeAfterRound` | 点击 `[1208,449,1,1]` 传送回本丸（U_每轮回本丸 启用） |
| `U_ContinueNextRound` | 点击 `[1067,558,120,79]` 继续下一层（默认） |

### 重伤处理

| 模式 | 节点链 | 说明 |
|------|--------|------|
| 修刀并继续 | `U_IsPreDamage1/2` → `U_LogPreDamage*` → `U_IsRepair` → `U_UseSpeedup` → `U_ConfirmRepair` | 修刀后 `U_ReturnHome` → `U_ClickMenuFromRepair` → 回本丸 |
| 修刀并停止 | 同上，`U_CheckAccel.next` → `U_ClickRepairandStop` | 修复完成后终止任务 |
| 停止 | `U_StopOnDamagePopup/Text` → `U_LogStopOnDamage*` → `U_NavigateToHomeFromStop` → `U_TerminateOnDamage` | 弹窗检测，停止任务 |
| 行军重伤 | `U_IsMarchingDamage` → `U_LogMarchingDamage` → `U_ReturnHomeAfterMarchDamage` → `U_ConfirmReturnHome` | 行军中检测到重伤立即撤退 |

## 重启游戏

```json
"U_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["U_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽 next 列表中节点不设 on_error
- 主枢纽 `on_error → U_RestartGame`
- 行军检测链路（`U_IsMarchingDamage`、`U_FatigueDetect`、`U_EqCheck`、`U_EqCheckTemplate`、`U_EqCheckC_*`）统一 `on_error → U_DetectWhereAmI`
- `U_CheckEquipmentPopup` / `U_StopOnEquipmentPopup` `on_error → U_ClickTeam`（选队页重试）
- `U_ConfirmSelectSlot` on_error → `U_LogNoDamagedSword`
- `U_VerifyMenuOpened` on_error → `U_ClickMenuForRepair`，`U_VerifyRepairMenuClosed` on_error → `U_SelectDamagedSword`（修复流程专用路由）
- 其余路由/识别节点统一 `on_error → U_DetectWhereAmI`

## 设计要点

- **地下城特有恢复节点**：修行书信、地下城教程、特殊掉落、连接中断，均为地下城独有
- **层数选择**：`U_SelectFloor` Custom 动作 + select 下拉搜索（1-99），不启用时绕过
- **行军检测平级化**：`U_CheckBeforeMarch.next` 平级扫描重伤/疲劳/刀装/回合完成，最后 `U_ClickMarching` 兜底前进
- **刀装保护**：`U_EqCheck` 路由 1 模板匹配 + 18 颜色网格，覆盖刀装破坏弹窗全场景
- **回本丸判定**：`U_CheckRoundComplete` OCR "传送凭证" 区分层数完成与继续前进
- **同步远征**：`U_IsHome.next` override 为 `["Expedition"]`
- **动画跳过**：`U_FallbackWait` 动作改为点击 `[180,11,25,28]` 跳过动画
