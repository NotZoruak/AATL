## 全任务通用节点（8 流水线共用）

以下 12 个节点/节点组出现在所有含主枢纽的流水线中。统一配置，仅前缀不同。

| `IsGameUpdatePopup` | 游戏更新弹窗 | TemplateMatch `游戏更新.png` | post_delay 2000 |
| `IsInGameUpdatePopup` | 游戏内更新 | OCR "更新" | post_delay 2000 |
| `FallbackWait` | 兜底等待 | DoNothing | next → 主枢纽 |
| `RestartGame` | 重启游戏 | Custom `RestartGameAction` | next → 主枢纽 |

### 主枢纽配置

7 个流水线使用 `DetectWhereAmI`（Expedition 使用入口节点 `Expedition`）：

```json
"X_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["X_RestartGame"],
    "next": [ ... ]
}
```

**卡死重启开启后**：`timeout` 由"卡死等待时间"覆盖，所有 `FallbackWait` 被禁用，失败穿透到 `RestartGame`。

## 全局选项涉及节点

### 卡死重启

所有 `*_FallbackWait`（S/M/LR/FB/D/U/G/E + `E_FlowerFallbackWait` + `FB_PostFallbackWait`）→ `enabled: false`。超时由"卡死等待时间"覆盖。

### 远征智能调度

开启时注入计时链路，关闭时不注入。

**开启 case**：

| 覆盖 | 值 |
|------|-----|
| `LR_IsTeamSelect.next` | `["E_CheckTimerExpired"]`（陆联选队页注入） |
| `E_AllTeamsBusy.action/next` | `DoNothing` / `["E_TrackerOCR"]`（独立远征） |
| `E_TrackerOCR` | enabled |
| `E_SmartWait` | enabled，`SmartWaitAction` |
| `E_WaitRefresh` | disabled |
| `E_ClickBackToHome.next` | `["E_SmartWait"]` |
| `E_VerifyLeftMenu.on_error` | `["E_SmartWait"]` |

**关闭 case**：无 override，`E_AllTeamsBusy` 走默认（Click 关面板 + `E_GoHome`），`E_TimerStart` 由 `ExpeditionTimerAction` 内部判断仅关面板不启计时。

### 长期远征计划

| 覆盖 | 值 |
|------|-----|
| `E_MarkTeamN.next` | `["E_UseTeamRecordN"]` |
| 疲劳阈值 | input，默认 91 |

### 换队长方式

Sortie/LRentaisen 的 `DragCaptain` 由全局选项控制策略（马匹/刀装/拖拽）。

## 远征计时的任务路由

`E_AllTeamsBusy` → `E_TimerStart`（`ExpeditionTimerAction`）。智能调度开启时 OCR 扫描 + 启计时 + 关面板；关闭时仅关面板。next 根据当前任务跳回：

| 任务 | `E_TimerStart.next` |
|------|---------------------|
| Sortie（合战场） | `S_NavigateToSortie` |
| Underground（地下城） | `U_NavigateToUnderground` |
| LRentaisen（陆联） | `LR_NavigateToActivity` |

由各自同步远征的 pipeline_override 设置。陆联的 `LR_IsTeamSelect → E_CheckTimerExpired` 由智能调度开启 case 注入，关闭时不注入。
