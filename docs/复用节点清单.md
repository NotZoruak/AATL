### 主枢纽配置

8 个流水线使用 `DetectWhereAmI`（Expedition 使用入口节点 `Expedition`）：

```json
"X_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["X_RestartGame"],
    "next": [ ... ]
}
```

**卡死重启开启后**：`timeout` 由"卡死等待时间"覆盖，所有 `FallbackWait` 被禁用，失败穿透到 `RestartGame`。

```
出战前重伤检出：
  IsPreDamage1（TemplateMatch）→ IsPreDamage2（OCR 复核）

      ├─ 修刀 → NavigateToRepair → ClickMenuForRepair（菜单→修复）
      │         → VerifyRepairMenuClosed → TryClickRepair
      │           → ClickRepairInMenu / SelectDamagedSword
      │             → FindSlot1~3（OCR "未使用"）→ ConfirmSelectSlot
      │               → CheckAccel → ClickAccel → ClickRepairDone（OCR "修复"）
      │                 → LogRepairDone → DirAfterRepair（OCR "目"）
      │                   → VerifyMenuAfterRepair → TryClickAfterRepair → 继续出阵
      └─ 停止 → IsStopOnDamage → StopOnDamagePopup/Text → 终止

修复画面直接检出（枢纽命中 IsRepair）：
  IsRepair（OCR "修复"）→ UseSpeedup（Click [1050,580]）
    → ConfirmRepair（Click [1050,580]）
      → ReturnHome → ClickMenuFromRepair（OCR "目"）
        → ClickHomeInMenu → 回本丸
```

### GUI「重伤处理」三种模式 pipeline_override

| 模式 | 启用节点 | 关键 override |
|------|---------|--------------|
| **修刀并继续** | `IsRepair`, `UseSpeedup`, `ConfirmRepair`, `ClickMenuFromRepair` | —（走完整修刀链路，回到出阵） |
| **修刀并停止** | `IsRepair`, `UseSpeedup`, `ConfirmRepair` | `CheckAccel.next` → `["ClickRepairandStop"]`（OCR "修复" + Click，无 next → 终止） |
| **停止** | `IsStopOnDamage`, `StopOnDamagePopup`, `StopOnDamageText` | `IsRepair.enabled` → false，`IsPreDamage1/2.enabled` → false |

## 全局选项涉及节点

### 卡死重启

所有 `*_FallbackWait`（S/M/LR/FB/D/U/G/E/TT + `E_FlowerFallbackWait` + `FB_PostFallbackWait`）→ `enabled: false`。超时由"卡死等待时间"覆盖。

### 远征智能调度

开启时注入计时链路，关闭时不注入。

**开启 case**：

| 覆盖 | 值 |
|------|-----|
| `LR_IsTeamSelect.next` | `["E_CheckTimerExpired"]`（陆联选队页注入） |
| `U_CheckRoundComplete.next` | `["E_CheckTimerExpired", "U_GoHomeAfterRound", "U_ContinueNextRound"]`（地下城传送凭证页注入） |
| `E_AllTeamsBusy.action/next` | `DoNothing` / `["E_TrackerOCR"]`（独立远征） |
| `E_TrackerOCR` | enabled |
| `E_SmartWait` | enabled，`SmartWaitAction` |
| `E_WaitRefresh` | disabled |
| `E_ClickBackToHome.next` | `["E_SmartWait"]` |
| `E_VerifyLeftMenu.on_error` | `["E_SmartWait"]` |

**关闭 case**：无 override，`E_AllTeamsBusy` 走默认（Click 关面板 + `E_GoHome`），`E_TimerStart` 由 `ExpeditionTimerAction` 内部判断仅关面板不启计时。

### 长期远征计划

| 覆盖 | 值 |
|------|-----|
| `E_MarkTeamN.next` | `["E_UseTeamRecordN"]` |
| 疲劳阈值 | input，默认 91 |

### 换队长方式

Sortie/LRentaisen 的 `DragCaptain` 由全局选项控制策略（马匹/刀装/拖拽）。

## 远征计时的任务路由

`E_AllTeamsBusy` → `E_TimerStart`（`ExpeditionTimerAction`）。智能调度开启时 OCR 扫描 + 启计时 + 关面板；关闭时仅关面板。next 根据当前任务跳回：

| 任务 | `E_TimerStart.next` | 计时器到期路径 |
|------|---------------------|---------------|
| Sortie（合战场） | `S_NavigateToSortie` | `E_CheckTimerExpired.on_error` → `E_GoHome` |
| Underground（地下城） | `U_NavigateToUnderground` | `E_CheckTimerExpired.on_error` → `U_GoHomeAfterRound` |
| LRentaisen（陆联） | `LR_NavigateToActivity` | `E_CheckTimerExpired.on_error` → `E_GoHome` |
| TacticalTraining（战术强化训练） | `TT_NavigateToActivity` | `E_CheckTimerExpired.on_error` → `E_GoHome` |

由各自同步远征的 pipeline_override 设置。陆联和战术强化训练的 `IsTeamSelect → E_CheckTimerExpired` 由智能调度开启 case 注入，关闭时不注入。
