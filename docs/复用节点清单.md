## 全任务通用配置

所有 `DetectWhereAmI` 枢纽（及 `Expedition` 入口）统一配置：

```json
"DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["X_RestartGame"],
    "next": [...]
}
```

- `timeout: 120000`（2 分钟）：枢纽超时后自动触发 `on_error`
- `on_error: ["X_RestartGame"]`：超时后调用 `RestartGameAction` 自定义动作（ADB 强杀 + 重启 `com.youzu.djlw`），然后回到枢纽重新检测

### 换队长

出现于 Sortie、LRentaisen、Underground。根据「换队长方式」全局选项决定使用点击式（马匹/刀装筛选）还是拖拽式（队内拖拽）。

**枢纽**：`S_ClickTeam` → `S_CaptainHub`（其他前缀同理）

```json
"CaptainHub": {
    "next": ["ClickCaptainSlot", "IsPreSortieConfirm"]
}
```

- 默认：`ClickCaptainSlot` 为 `enabled: false`，跳过换队长直接进确认
- 勾选「换队长」复选框：启用点击式链路（马匹/刀装筛选）
- 全局「换队长方式」= 队内拖拽：`CaptainHub.next` 覆盖为 `["DragCaptain", "IsPreSortieConfirm"]`

**点击式链路**（马匹/刀装筛选，全部默认 `enabled: false`）：

```json
"IsSwordSelect": {
    "recognition": { "type": "OCR", "param": { "roi": [530, 6, 224, 45], "expected": "刀剑男士选择" } },
    "enabled": false,
    "next": ["ClickCaptain1"]
}
```

```json
"DetectSortOrder": {
    "enabled": false,
    "next": ["ClickDescending", "ConfirmSortAsc"]
}
```

`DetectSortOrder` 为纯路由节点，无 recognition。确保在刀剑选择页面后再进入排序流程。

```json
"ClickDescending": {
    "recognition": { "type": "OCR", "param": { "roi": [939, 77, 56, 39], "expected": "降序" } },
    "enabled": false,
    "action": { "type": "Click", "param": { "target_offset": [4, 2, 0, 0] } },
    "next": ["ConfirmSortAsc"]
}
```

- OCR "降序" 确认当前为降序排列，点击切换

```json
"ConfirmSortAsc": {
    "recognition": { "type": "OCR", "param": { "roi": [939, 77, 56, 39], "expected": "升序" } },
    "enabled": false,
    "action": { "type": "Click", "param": { "target": [1189, 140, 37, 1], "target_offset": [4, 2, 0, 0] } },
    "next": ["ClickCaptain1"]
}
```

- OCR "升序" 确认已切换为升序（疲劳值从低到高），点击确认
- 两个节点共用同一个 OCR ROI `[939, 77, 56, 39]`

```json
"ClickCaptain1" ~ "ClickCaptain5": {
    "enabled": false,
    "action": { "type": "Click", "param": { "target": "(各位置)", "target_offset": [8, 0, 0, 0] } },
    "post_delay": 800,
    "next": ["ClickCaptain2"]  // 依次链到 Captain5
}
// ClickCaptain5.next → ["ClickCaptainSlot"]
```

```json
"ClickCaptainSlot": {
    "enabled": false,
    "action": { "type": "Click", "param": { "target": [132, 74, 1, 1], "target_offset": [8, 0, 0, 0] } },
    "post_delay": 1000,
    "next": ["IsPreSortieConfirm"]
}
```

**拖拽式链路**（队内拖拽）：

```json
"DragCaptain": {
    "enabled": false,
    "action": {
        "type": "Custom",
        "custom_action": "DragCaptainAction"
    },
    "next": ["IsPreSortieConfirm"]
}
```

- OCR 六个位置的疲劳值，找最低值，长按 1s + 拖拽 500ms 换到队长槽
- 子选项「拖拽跳过位置」：被跳过的位置不参与疲劳值比较
- 三种换队长方式统一受各任务「换队长」复选框控制

### 日志动作

所有重伤日志节点均使用同一个 `DamageLogAction` 自定义动作，仅 message 不同：

| 节点 | message |
|------|---------|
| `LogPreDamage1` | `[重伤检测] 检测到刀剑男士重伤，准备进入修复流程` |
| `LogPreDamage2` | `[重伤检测] 检测到刀剑男士重伤，准备进入修复流程` |
| `LogMarchingDamage2` | `[重伤检测] 检测到刀剑男士重伤，撤退撤退` |
| `LogStopOnDamage` | `[重伤检测] 检测到刀剑男士重伤` → `NavigateToHomeFromStop` |
| `LogStopOnDamageText` | `[重伤检测] 检测到刀剑男士重伤` → `NavigateToHomeFromStop` |
| `LogStopOnDamageRepair` | `[重伤检测] 检测到刀剑男士重伤，任务终止`（待定） |
| `TerminateOnDamage` | 使用 `StopOnDamageAction`：当前任务终止 + 系统托盘通知 |

```json
"LogMarchingDamage2": {
    "action": { "type": "Custom", "custom_action": "DamageLogAction", "custom_action_param": { "message": "[重伤检测] 检测到刀剑男士重伤，撤退撤退" } },
    "next": ["ReturnHomeAfterMarchDamage"]
}
```

## 远征共用节点

以下节点定义在 `Expedition.json` 中，被独立远征和同步远征（陆联/合战场/地下城）共同使用。

### 计时器节点

```json
"E_TimerStart": {
    "action": {
        "type": "Custom",
        "custom_action": "ExpeditionTimerAction",
        "custom_action_param": { "mode": "start" }
    },
    "next": []
}
```

- `custom_action_param.interval`（秒）由 `MaaProcessor` 从远征间隔自动注入
- `next` 由同步远征 pipeline_override 按任务设置：
  - 合战场：`"S_NavigateToSortie"`
  - 陆联：`"LR_NavigateToUnderground"`
  - 地下城：`"U_NavigateToUnderground"`
- 当全局开关「远征智能调度」开启时，`ExpeditionTimerAction` 会自动 OCR 队伍面板剩余时间，动态调整计时器间隔

```json
"E_CheckTimerExpired": {
    "action": {
        "type": "Custom",
        "custom_action": "ExpeditionTimerCheckAction"
    },
    "next": ["LR_SelectDifficulty"],
    "on_error": ["E_GoHome"]
}
```

- `ExpeditionTimerCheckAction` 返回 `true`（未过期）→ `next` 继续出阵，**不触发截图**
- 返回 `false`（过期）→ `on_error → E_GoHome` 回本丸远征，仅此时截图
- `next` 和 `on_error` 的默认值为陆联配置，合战场和地下城通过 pipeline_override 覆盖为各自的目标节点

```json
"E_TimerReset": {
    "action": {
        "type": "Custom",
        "custom_action": "ExpeditionTimerAction",
        "custom_action_param": { "mode": "reset" }
    },
    "next": []
}
```

### 智能调度节点

以下节点默认 `enabled: false`，由全局开关「远征智能调度」的 pipeline_override 启用。

```json
"E_TrackerOCR": {
    "enabled": false,
    "action": {
        "type": "Custom",
        "custom_action": "ExpeditionTimeTracker"
    },
    "next": ["E_GoHome"],
    "pre_delay": 500
}
```

- 独立远征中在 `E_AllTeamsBusy` 之后执行，OCR 队伍面板剩余时间后点击关闭面板
- 同步远征中不经过此节点（`E_TimerStart` 内部直接调用 OCR 逻辑）

```json
"E_SmartWait": {
    "enabled": false,
    "action": {
        "type": "Custom",
        "custom_action": "SmartWaitAction"
    },
    "next": ["Expedition"]
}
```

- 仅独立远征使用，替代 `E_WaitRefresh` 的固定 `post_delay`
- 读取 `ExpeditionReturnTracker` 的最早归队时间，取与远征间隔的较小值动态 sleep

### 同步远征 pipeline_override

各任务勾选「同步远征」后的覆盖规则：

| 节点 | 覆盖 | 说明 |
|------|------|------|
| `{前缀}IsHome.next` | `["E_CheckTimerExpired"]` *¹ | 回到本丸后先检查计时器 |
| `E_CheckTimerExpired.next` | `["{前缀}NavigateTo..."]` | 未过期 → 跳过远征回活动 |
| `E_CheckTimerExpired.on_error` | `["Expedition"]` *¹ | 过期 → 进入远征枢纽 |
| `E_AllTeamsBusy.next` | `["E_TimerStart"]` | 全部忙线后启动计时器 |
| `E_TimerStart.next` | `["{前缀}NavigateTo..."]` | 启动后回活动页 |
| `{前缀}IsEventPage.next` | `["E_CheckTimerExpired"]` *² | 活动页先检查计时器 |

> *¹ 合战场使用此模式（每轮结束自然回本丸）。  
> *² 陆联/地下城使用此模式（每轮结束回活动页）。

### 自定义类

| 类 | 接口 | 说明 |
|------|------|------|
| `ExpeditionTimerAction` | `IMaaCustomAction` | 启动/重置倒计时，智能调度时自动 OCR 队伍面板 |
| `ExpeditionTimerCheckAction` | `IMaaCustomAction` | 比较当前时间与记录时间，控制路由 |
| `ExpeditionTimerRecognition` | `IMaaCustomRecognition` | 备用识别（当前未在流水线中使用） |
| `ExpeditionTimeTracker` | `IMaaCustomAction` | OCR 队伍面板剩余时间，存入 `ExpeditionReturnTracker` |
| `SmartWaitAction` | `IMaaCustomAction` | 读取追踪器计算动态等待时长，替代固定 `post_delay` |
| `ExpeditionReturnTracker` | 静态类 | 存储最早归队时间戳，供多个动作共享 |

注册位置：`MaaProcessor.RegisterCustomRecognitionsAndActions`
