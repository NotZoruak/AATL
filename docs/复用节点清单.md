# 复用节点清单

本文档记录跨任务 pipeline 复用的公共节点。所有节点仅前缀不同（`S_` / `LR_` / `U_` / `FB_` / `G_` / `D_` / `M_` / `EC_` / `E_`），结构完全一致。

## 全任务通用配置

所有 `DetectWhereAmI` 枢纽（及 `Expedition` 入口）统一配置：

```json
"DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["X_RestartGame"],
    "next": [...]
}
```

- `timeout: 120000`（2 分钟）：枢纽超时后自动触发 `on_error`
- `on_error: ["X_RestartGame"]`：超时后调用 `RestartGameAction` 自定义动作（ADB 强杀 + 重启 `com.youzu.djlw`），然后回到枢纽重新检测

## 新增任务检查清单

新增 pipeline 时确保以下节点已配置（替换前缀）：

- [ ] `IsAnnouncementPopup` — 自循环 + on_error → hub
- [ ] `IsLoginReward` + `LoginRewardClick2` + `LoginRewardClick3` — 三击关闭
- [ ] `HasExpeditionReturn_Exp` + `HasExpeditionReturn_Title` — 远征归来
- [ ] `IsBattleResult_Exp` + `IsBattleResult_Title` — 战斗结果
- [ ] `IsSwordDropColor` — 刀剑掉落
- [ ] `IsGameIcon` + `IsLoginButton` — 闪退恢复
- [ ] `IsGameUpdatePopup` + `IsInGameUpdatePopup` — 更新弹窗
- [ ] `IsInternalReport` — 内番报告
- [ ] `FallbackWait` — 兜底等待
- [ ] `CheckHomeBrightness` + `IsHome` — 本丸检测
- [ ] `IsMenuDirectory` — 菜单目录
