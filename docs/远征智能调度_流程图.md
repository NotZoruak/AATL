# 远征智能调度 v2 — 流程图验证

## 合战场 + 同步远征

### 智能调度 开启

```mermaid
flowchart TD
    S_Entry["Sortie 入口"] --> S_DWAI["S_DetectWhereAmI<br/>识别当前画面"]
    S_DWAI --> S_IsHome["S_IsHome<br/>TemplateMatch 本丸"]
    S_IsHome -->|"✅ 智能调度 开启<br/>next: E_CheckTimerExpired"| E_CTE["E_CheckTimerExpired<br/>ExpeditionTimerCheckAction"]
    
    E_CTE -->|"⏱ 未到期<br/>next: S_NavigateToSortie<br/>✅ S_同步远征"| S_NTS["S_NavigateToSortie<br/>继续出阵"]
    S_NTS --> S_DWAI
    
    E_CTE -->|"⏰ 已到期<br/>on_error: Expedition<br/>✅ S_同步远征"| EXP["Expedition 管线"]
    EXP --> E_AllBusy["E_AllTeamsBusy<br/>DirectHit"]
    E_AllBusy -->|"✅ 智能调度<br/>DoNothing → E_TrackerOCR"| E_Tracker["E_TrackerOCR<br/>ExpeditionTimeTracker<br/>OCR 扫描归队时间"]
    E_Tracker --> E_GoHome["E_GoHome → E_ClickDirectoryTop"]
    E_GoHome --> E_Smart["E_SmartWait<br/>SmartWaitAction<br/>取 min(最早归队, 间隔)"]
    E_Smart --> E_TS["E_TimerStart<br/>✅ S_同步远征<br/>next: S_NavigateToSortie"]
    E_TS --> S_DWAI
```

## 陆联 + 同步远征

### 智能调度 开启

```mermaid
flowchart TD
    LR_Event["陆联活动进行中"] --> LR_Home["LR_IsHome<br/>回到本丸"]
    LR_Home -->|"✅ LR_同步远征<br/>next: Expedition"| EXP["Expedition 管线<br/>处理远征"]
    EXP --> LR_Back["回到活动"]
    
    LR_Event --> LR_Team["LR_IsTeamSelect<br/>选择部队"]
    LR_Team -->|"✅ 智能调度 开启<br/>next: E_CheckTimerExpired"| E_CTE["E_CheckTimerExpired<br/>ExpeditionTimerCheckAction"]
    E_CTE -->|"⏱ 未到期<br/>next: LR_ClickTeam<br/>✅ LR_同步远征"| LR_Continue["继续活动"]
    E_CTE -->|"⏰ 已到期<br/>on_error: E_GoHome<br/>✅ LR_同步远征"| LR_GoHome["E_GoHome → 回本丸"]
    LR_GoHome --> EXP
```

### 智能调度 关闭

```mermaid
flowchart TD
    LR_Event["陆联活动进行中"] --> LR_Home["LR_IsHome<br/>回到本丸"]
    LR_Home -->|"✅ LR_同步远征<br/>next: Expedition"| EXP["Expedition 管线<br/>处理远征"]
    EXP --> LR_Back["回到活动"]
    
    LR_Event --> LR_Team["LR_IsTeamSelect<br/>选择部队"]
    LR_Team -->|"默认行为<br/>无计时器 override"| LR_Continue["继续活动"]
```

## 节点归属

| 节点 | 设置来源 |
|------|---------|
| S_IsHome.next | 智能调度（开启→E_CheckTimerExpired，关闭→E_CheckTeamStatus） |
| E_CheckTimerExpired.next/on_error | S_同步远征（next→S_NavigateToSortie, on_error→Expedition） |
| E_TimerStart.next | S_同步远征 / LR_同步远征（任务特定） |
| E_AllTeamsBusy.next | 智能调度（开启→E_TrackerOCR，关闭→E_TimerStart） |
| LR_IsTeamSelect.next | 智能调度（仅开启→E_CheckTimerExpired） |
| LR_IsHome.next | LR_同步远征（→Expedition） |
