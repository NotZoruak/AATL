# 战术强化训练（TT）任务设计

## 概述

战术强化训练（通称巧克力/南瓜），同一个活动模板，操作完全一致。

- 流水线文件：`assets/resource/base/pipeline/TacticalTraining.json`
- 入口节点：`TacticalTraining`
- 主枢纽：`TT_DetectWhereAmI`
- 节点前缀：`TT_`

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| TT_选择部队 | select | 部队一～五，默认部队一 |
| TT_选择难度 | select | 初级/中级/上级，默认初级 |
| TT_换队长 | checkbox | 队内拖拽换队长 |
| TT_不购买门票 | checkbox | 令牌不足时停止任务而非购买 |
| TT_同步远征 | checkbox | 回本丸后自动派遣远征 |

```json
{
    "name": "战术强化训练",
    "entry": "TacticalTraining",
    "default_check": false,
    "repeatable": true,
    "option": ["TT_选择部队", "TT_选择难度", "TT_换队长", "TT_不购买门票", "TT_同步远征"]
}
```

## 主枢纽 `TT_DetectWhereAmI`

21 个检测节点，`timeout: 120000`，`on_error → TT_RestartGame`。

```json
"TT_DetectWhereAmI": {
    "pre_delay": 0,
    "timeout": 120000,
    "on_error": ["TT_RestartGame"],
    "next": [
        "TT_IsAnnouncementPopup", "TT_IsLoginReward",
        "TT_IsEventPage", "TT_IsSilhouettePopup",
        "TT_IsTicketReplenishPage", "TT_CheckHomeBrightness",
        "TT_IsTeamSelect", "TT_IsSwordSelect",
        "TT_IsSortie", "TT_HasExpeditionReturn_Exp",
        "TT_HasExpeditionReturn_Title", "TT_IsBattleResult_Exp",
        "TT_IsBattleResult_Title", "TT_IsSwordDropColor",
        "TT_IsConnectionInterrupted", "TT_IsGameIcon",
        "TT_IsLoginButton", "TT_IsGameUpdatePopup",
        "TT_IsInGameUpdatePopup", "TT_IsInternalReport",
        "TT_FallbackWait"
    ]
}
```

## 主流程链路

```
TT_DetectWhereAmI（枢纽）
   ├── 活动页 → TT_IsEventPage（TemplateMatch "战术强化训练.png"）
   │     → TT_ClickDifficulty → TT_VerifyEventPage
   │       ├── TT_CheckSilhouette（剪影更新检测）
   │       │     → TT_IsSilhouettePopup → TT_ConfirmSilhouette
   │       │     TT_TicketGate（令牌不足）→ TT_IsTicketReplenishPage
   │       └── TT_EnterEvent（点击进入活动）→ TT_IsTeamSelect
   │
   ├── 部队选择 → TT_IsTeamSelect（OCR "部队选择"）
   │     → TT_ClickTargetTeam（post_delay 800）
   │       → TT_CheckCaptainColor（队长红点检测）
   │         ├── 命中 → TT_CaptainHub → TT_DragCaptain / TT_IsPreSortieConfirm
   │         └── 未命中 → TT_TryTeam1~5（依次尝试其他部队）
   │               → 全失败 → TT_AllTeamsExhausted（任务终止）
   │     → TT_IsPreSortieConfirm（OCR "即刻"）→ TT_ClickSortieNow
   │
   ├── 行军循环 → TT_IsBattleResult_Exp / _Title（跳过结算）
   │     → TT_IsSwordDropColor（捡掉落）→ TT_CheckRoundComplete
   │       → 回枢纽重新分发
   │
   ├── 令牌补充 → TT_IsTicketReplenishPage（OCR "更新令牌补充"）
   │     → TT_ConfirmTicketReplenish → TT_CloseTicketDialog1/2/3
   │     （不购买门票时：TT_TicketGate → TT_TerminateNoTicket 终止）
   │
   ├── 回本丸 → TT_CheckHomeBrightness → TT_IsHome
   │     → TT_NavigateToActivity → TT_ClickMenu（OCR "目"）
   │       → TT_PostClickMenuHub → TT_IsMenuDirectory
   │       → TT_ClickActivityInMenu（OCR "出阵"）
   │
   └── 闪退恢复 / 弹窗关闭 / TT_FallbackWait
```

## 难度选择

`TT_IsEventPage` TemplateMatch `Activity/战术强化训练.png`（ROI `[429,69,289,52]`，阈值 0.98）。`TT_ClickDifficulty` target 由选项覆盖（初级 `[143,213]` / 中级 `[300,213]` / 上级 `[440,213]`）。`TT_VerifyEventPage` 二次验证。

## 部队选择与换队长

`TT_IsTeamSelect` OCR "部队选择"（ROI `[561,1,160,49]`）→ `TT_ClickTargetTeam` 点击选项指定的部队，target 由选项覆盖（`[154,93]` 等五个位置）。`TT_CheckCaptainColor` ColorMatch 检测红色队长标记（ROI `[1199,623,8,7]`，upper `[178,27,27]`，lower `[172,21,21]`）。

命中 → `TT_CaptainHub`（勾选「换队长」时走 `TT_DragCaptain` → `DragCaptainAction`，否则直接到 `TT_IsPreSortieConfirm`）。未命中 → 依次尝试其他部队（TT_TryTeam1~5），全失败则 `TT_AllTeamsExhausted` 终止任务。

## 剪影更新与令牌

`TT_CheckSilhouette` OCR "更新"（ROI `[308,407,140,36]`）检测是否需要更新剪影。`TT_IsSilhouettePopup` OCR "更新"（ROI `[593,58,93,39]`）→ 默认 next：`[TT_ConfirmSilhouette, TT_TicketGate]`。勾选「不购买门票」后改为 `[TT_ConfirmSilhouette, TT_TerminateNoTicket]`。

`TT_ConfirmSilhouette` ColorMatch 金色确认按钮（ROI `[564,593,32,25]`），`TT_TicketGate` ColorMatch 灰色按钮（同位置），点击令牌图标进入购买页。购买链：`TT_IsTicketReplenishPage` → `TT_ConfirmTicketReplenish` → `TT_CloseTicketDialog1/2/3`（连续 3 次关闭弹窗）。

## 行军循环

战斗结算由主枢纽直接分发：`TT_IsBattleResult_Exp` / `TT_IsBattleResult_Title`（跳过结算）→ `TT_IsSwordDropColor`（ColorMatch 捡掉落，ROI `[598,543,66,1]`）→ `TT_CheckRoundComplete`（TemplateMatch `Activity/战术强化训练.png`）→ 回枢纽。全程靠枢纽循环驱动，不依赖 `next` 串联。

## 闪退恢复

| 节点 | 识别 | 动作 |
|------|------|------|
| `TT_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png` | 自循环关闭 |
| `TT_IsLoginReward` | TemplateMatch `登录奖励.png` | 三击领取 |
| `TT_IsGameIcon` | TemplateMatch `游戏图标.png` | 点击重进 |
| `TT_IsLoginButton` | TemplateMatch `登录.png` | 点击登录 |
| `TT_IsGameUpdatePopup` | TemplateMatch `游戏更新.png` | 关闭弹窗 |
| `TT_IsInGameUpdatePopup` | OCR "更新" | 关闭弹窗 |
| `TT_IsInternalReport` | TemplateMatch `内番报告.png` | 关闭弹窗 |
| `TT_IsConnectionInterrupted` | OCR "连接中断" | 点击重连 |
| `TT_FallbackWait` | DoNothing | 兜底等待 |

## 重启游戏

```json
"TT_RestartGame": {
    "action": { "type": "Custom", "custom_action": "RestartGameAction" },
    "next": ["TT_DetectWhereAmI"]
}
```

## on_error 覆盖

- 主枢纽子节点 `on_error → TT_DetectWhereAmI`
- 主枢纽自身 `on_error → TT_RestartGame`
- `TT_AllTeamsExhausted`、`TT_TerminateNoTicket`：空 next，终止任务

## 同步远征集成

勾选后 `TT_IsHome.next` 改为 `["Expedition"]`，`TT_WaitRefresh` 启用。远征检查点在 `TT_IsTeamSelect` → `E_CheckTimerExpired`（由「远征智能调度」全局选项注入），计时器到期后回本丸补派。
