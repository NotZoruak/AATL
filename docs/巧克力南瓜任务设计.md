# 巧克力 / 南瓜活动任务设计

## 概述

巧克力/南瓜是同一个活动（不同时期叫法不同），操作完全一致。

| 项目 | 内容 |
|------|------|
| 流水线文件 | `resource/base/pipeline/EventFarm.json` |
| 入口节点 | `EventFarm` |
| 节点前缀 | `CP_` |
| 活动模板 | `巧克力南瓜.png`（TemplateMatch） |
| 参考实现 | `LRentaisen.json`（陆联，更复杂）、`Expedition.json`（远征同步集成） |

## GUI 选项

| 选项 | 类型 | 说明 |
|------|------|------|
| 部队选择 | select | 部队一 ~ 部队五，默认部队一 |
| 换队长 | switch | 开启后按陆联逻辑轮换队长 |
| 同步远征 | switch | 全队忙线后启动远征计时器，回到活动继续出阵 |
| 远征智能调度 | switch（全局） | 按最短间隔检查并补派 |
| 卡死重启 | switch（全局） | 流水线卡死时自动重启模拟器并重进游戏 |

换队长方式与陆联完全一致：`CP_DetectSortOrder` → `CP_ClickDescending` / `CP_ConfirmSortAsc` → `CP_ClickCaptain1~5`，默认 `enabled: false`，由「换队长」开关统一启用。

## 主枢纽 `CP_DetectWhereAmI`

```json
"CP_DetectWhereAmI": {
    "pre_delay": 0,
    "next": [
        "CP_IsAnnouncementPopup",
        "CP_IsLoginReward",
        "CP_IsEventPage",
        "CP_CheckHomeBrightness",
        "CP_IsTeamSelect",
        "CP_IsSwordSelect",
        "CP_IsSortie",
        "CP_HasExpeditionReturn_Exp",
        "CP_HasExpeditionReturn_Title",
        "CP_IsBattleResult_Exp",
        "CP_IsSwordDropColor",
        "CP_IsSpecialDrop",
        "CP_IsConnectionInterrupted",
        "CP_IsGameIcon",
        "CP_IsLoginButton",
        "CP_IsGameUpdatePopup",
        "CP_IsInGameUpdatePopup",
        "CP_IsInternalReport",
        "CP_FallbackWait"
    ],
    "timeout": 120000,
    "on_error": ["CP_RestartGame"]
}
```

> 节点说明：
> - `CP_IsBattleResult_Exp`：OCR "经验"，战斗结算页点击关闭
> - `CP_IsSwordDropColor`：ColorMatch 刀剑掉落颜色，点击关闭再进
> - `CP_IsConnectionInterrupted`：OCR "连接中断"，点击重连
> - `CP_IsSpecialDrop`：OCR "完成|撤退"，特殊掉落页点击关闭
> - 无 `CP_CheckSwordDropAfterSpecial`：该活动无特殊掉落后的额外检测需求
> - 无 `CP_IsTicketPopup` / `CP_IsReplenishDone`：门票补给只在剪影链路中弹出

## 主流程

```
EventFarm（入口）
  → CP_DetectWhereAmI（主枢纽）
     ├── CP_IsAnnouncementPopup → 点击关闭，回到枢纽
     ├── CP_IsLoginReward → 连击关闭，回到枢纽
     ├── CP_IsEventPage（TemplateMatch 活动页面.png）
     │     → CP_ClickDifficulty（点击难度按钮）
     │       → CP_VerifyEventPage（TemplateMatch 活动页面.png 双重确认）
     │         → CP_CheckSilhouette（ColorMatch 剪影更新检测）
     │              ├─ 命中 → CP_ClickSilhouette（点击进入剪影更新）
     │              │          next: [CP_SilhouetteChain, CP_IsSwordDropColor]
     │              │          → CP_SilhouetteChain（占位，活动开启后补充）
     │              │          → 链路中可能出现门票补充弹窗
     │              └─ 未命中 → CP_EnterEvent（点击进入按钮）
     │
     ├── CP_CheckHomeBrightness → CP_IsHome → CP_NavigateToActivity
     ├── CP_IsSortie → CP_OnSortieScreen → 回到枢纽
     ├── CP_HasExpeditionReturn_Exp / _Title → 关闭远征归来弹窗
     ├── CP_IsBattleResult_Exp → 点击关闭战斗结算页
     ├── CP_IsSwordDropColor → 点击关闭掉落页
     ├── CP_IsSpecialDrop → 点击关闭特殊掉落页
     ├── CP_IsConnectionInterrupted → 点击重连
     ├── CP_IsTeamSelect → 部队选择流程
     └── 闪退恢复节点（IsGameIcon/IsLoginButton/...）
```

### 活动页面进入链路（详细）

```
CP_IsEventPage（TemplateMatch 活动页面.png）
  └─ action: Click → CP_ClickDifficulty
     │
CP_ClickDifficulty（点击难度按钮）
  └─ action: Click → next: [CP_VerifyEventPage]
     │
CP_VerifyEventPage（TemplateMatch 活动页面.png，双重确认）
  └─ next: [CP_CheckSilhouette]
     │
CP_CheckSilhouette（ColorMatch 剪影检测）
  ├─ 命中 → next: [CP_ClickSilhouette]
  └─ 未命中 → next: [CP_EnterEvent]
     │
CP_ClickSilhouette（点击剪影更新按钮，进入更新剪影链路）
  └─ action: Click
     next: [CP_SilhouetteChain, CP_IsSwordDropColor]
     CP_IsSwordDropColor 用于在更新剪影过程中拦截意外出现的掉落页
     │
CP_SilhouetteChain（OCR 识别剪影更新弹窗 → 点击确认）
  └─ recognition: OCR "更新"
     action: Click → next: [CP_DetectWhereAmI]
     │
CP_EnterEvent（点击进入按钮）
  └─ action: Click → next: [CP_DetectWhereAmI]
```

### 部队选择与换队长链路

```json
"CP_IsTeamSelect": {
    "recognition": { "type": "OCR", "param": { "roi": [561, 1, 160, 49], "expected": "部队选择" } },
    "next": ["CP_ClickTargetTeam"]
}
```

```
CP_IsTeamSelect（OCR "部队选择"）
  → CP_ClickTargetTeam（点击目标部队标签）
    → CP_CheckCaptainColor（ColorMatch 颜色检测）
       ├─ 命中 → CP_SwapCaptain（若换队长开关开启）
       │          → CP_ClickSortieNow → 回到枢纽
       └─ 未命中 → CP_TryTeam1
                    ├─ 颜色命中 → CP_SwapCaptain → CP_ClickSortieNow
                    └─ 未命中 → CP_TryTeam2 → ... → CP_TryTeam5
                                 └─ 全部未命中 → CP_AllTeamsExhausted（任务终止）
```

换队长逻辑与陆联 `LR_CaptainHub` 模式一致，`CP_SwapCaptain`、`CP_ClickCaptain1~5`、`CP_DetectSortOrder` 等节点默认 `enabled: false`，由「换队长」开关统一启用。

### 门票补充弹窗

> ⚠️ 活动开启后确认具体弹出时机和识别内容。当前规划：

门票补给弹窗**只在剪影更新链路中**出现（`CP_SilhouetteChain` 点击确认之后），不在即刻出阵后出现。放在剪影链路之后作为 next 分支，结构与陆联 `LR_HandleTicketPopup` 一致：

```
CP_SilhouetteChain
  → CP_HandleTicketPopup（路由）
       ├─ CP_ReplenishTicket（购买门票）→ CP_ClickRestore3 → CP_ClickReplenishConfirm → 继续出阵
       └─ CP_TerminateNoTicket（不购买 → 终止任务）
```

## 同步远征集成

与陆联完全相同的模式。同步远征开启时，通过 `pipeline_override` 将 CP 任务与远征流水线交叉连接：

```
CP_IsHome → Expedition（先检查远征）
  → ...远征派遣...
    → E_AllTeamsBusy → E_TimerStart → CP_NavigateToActivity（回到活动）
      → ...出阵循环...
        → CP_IsTeamSelect → E_CheckTimerExpired
           ├─ 未过期(next) → CP_ClickTeam（继续出阵）
           └─ 已过期(on_error) → E_GoHome → Expedition（回远征）
```

| 覆盖节点 | 覆盖值 | 说明 |
|----------|--------|------|
| `CP_IsHome.next` | `["Expedition"]` | 回到本丸时跳远征 |
| `E_AllTeamsBusy.next` | `["CP_NavigateToActivity"]` | 忙线回到活动 |
| `E_TimerStart.next` | `["CP_NavigateToActivity"]` | 计时器启动后回到活动 |
| `E_ClickBackToHome.next` | `["CP_WaitRefresh"]` | 远征结束回到活动 |
| `CP_IsTeamSelect.next` | `["E_CheckTimerExpired"]` | 出阵前检查计时器，过期回远征 |
| `E_CheckTimerExpired.next` | `["CP_ClickTeam"]` | 未过期继续出阵 |
| `E_CheckTimerExpired.on_error` | `["E_GoHome"]` | 已过期回远征 |
| `E_SelectMapN.action` | `ExpeditionMapSelectAction` | 直接选图 |
| `E_ClickSmallMapN.enabled` | `false` | 禁用小地图点击 |

## 闪退恢复节点

复用陆联/远征的标准恢复节点集合：

| 节点 | 识别 | 动作 |
|------|------|------|
| `CP_IsAnnouncementPopup` | TemplateMatch `公告弹窗.png`，timeout 3000 | 自循环点击关闭 |
| `CP_IsLoginReward` | TemplateMatch `登录奖励.png` | 连击关闭 |
| `CP_IsInternalReport` | TemplateMatch `内番报告.png` | 点击关闭 |
| `CP_IsGameIcon` | TemplateMatch `游戏图标.png`（全屏），post_delay 3000 | 点击重进 |
| `CP_IsLoginButton` | TemplateMatch `登录.png`，post_delay 3000 | 点击登录 |
| `CP_IsGameUpdatePopup` | TemplateMatch `游戏更新.png`，post_delay 2000 | 关闭弹窗 |
| `CP_IsInGameUpdatePopup` | OCR "更新"，post_delay 2000 | 关闭弹窗 |
| `CP_FallbackWait` | DoNothing | 回枢纽 |

## 设计要点

- **模板**：`巧克力南瓜.png`
- **剪影链路**：`CP_SilhouetteChain` OCR 识别"更新剪影"弹窗并点击确认
- **剪影点击节点的 next**：同时包含剪影更新链路和刀剑掉落检测，避免更新过程中因掉落弹窗卡死
- **门票不同于陆联**：只在剪影更新链路中弹出，不在即刻出阵后出现
- **无战斗循环**：点完即刻出阵直接回枢纽，不跟踪行军/阵形/战斗结果
- **全队耗尽终止**：部队一~五全部未命中颜色条件时终止任务
- **换队长同陆联**：队长轮换逻辑完全复用，editorKeyOverride 统一在代码层处理
- **on_error 规范**：所有 Click 节点若 `next` 指向识别节点，必须配置 `on_error`；路由节点同理
