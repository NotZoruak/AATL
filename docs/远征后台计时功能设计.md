# 远征后台计时功能设计

## 概述

当前同步远征在全部队伍忙线后，每次 LR 回本丸仍会进入远征流水线做无效检查。本功能在全部忙线后启动后台倒计时，LR 回到活动页面时检查倒计时：归零则主动回本丸检查远征，未归零则继续出阵。

- 计时器数值来源：远征任务的 `RefreshInterval`（刷新间隔）
- 首次运行：timer 为 null → 视为过期 → 立即检查
- 全部忙线后：启动倒计时
- LR 回到活动页面时：归零 → 主动回本丸远征；未归零 → 继续出阵

## 技术方案

### 新增类

#### `ExpeditionTimerRecognition`（自定义识别）

- 实现 `IMaaCustomRecognition`
- `Run()` 返回 `true`=命中（timer 过期/null），`false`=未命中（timer 未到）
- 静态字段 `_nextCheckTime` 存储下次检查时间
- 命中走 `next`，未命中走 `on_error`

#### `ExpeditionTimerAction`（自定义动作）

- 实现 `IMaaCustomAction`
- 调用 `ExpeditionTimerRecognition.StartTimer(intervalSeconds)` 记录倒计时起点
- `interval` 参数从 `custom_action_param` 获取，由 pipeline_override 注入

### 新增流水线节点（Expedition.json）

```json
"E_TimerStart": {
    "action": {
        "type": "Custom",
        "custom_action": "ExpeditionTimerAction"
    },
    "next": []
},
"E_CheckTimerExpired": {
    "recognition": {
        "custom_recognition": "ExpeditionTimerRecognition"
    },
    "next": [],
    "on_error": []
}
```

节点自身的 `next`/`on_error`/`custom_action_param` 为空，由同步远征的 pipeline_override 动态注入。

### pipeline_override 覆盖（陆联）

| 节点 | 覆盖字段 | 新值 | 说明 |
|------|----------|------|------|
| `E_AllTeamsBusy` | `next` | `["E_TimerStart"]` | 全部忙线后启动计时器 |
| `E_TimerStart` | `custom_action_param` | `{"interval":600}` | 注入间隔值 |
| `E_TimerStart` | `next` | `["LR_NavigateToUnderground"]` | 启动后继续陆联 |
| `LR_IsEventPage` | `next` | `["E_CheckTimerExpired"]` | 回到活动页面先检查计时器 |
| `E_CheckTimerExpired` | `next` | `["E_GoHome"]` | 过期 → 回本丸远征 |
| `E_CheckTimerExpired` | `on_error` | `["LR_SelectDifficulty"]` | 未过期 → 继续出阵 |
| `LR_IsHome` | `next` | `["Expedition"]` | 已在本丸则直接远征（不变） |

### MaaProcessor 自动注入 interval

在 `CreateNodeAndParam` 的同步远征处理逻辑中，读取远征任务 `RefreshInterval` 的 `seconds` 输入值，注入 `E_TimerStart.custom_action_param.interval`。

### 注册

在 `RegisterCustomRecognitionsAndActions` 中：
```csharp
tasker.Resource.Register(new Custom.ExpeditionTimerAction());
tasker.Resource.Register(new Custom.ExpeditionTimerRecognition());
```

## 运行流程

```
LR 启动（在本丸）
    │
    └─ LR_IsHome → Expedition → 检查队伍 → 派遣空闲队伍
           │
           ├─ 有队伍空闲 → 派遣 → E_ClickBackToHome → LR_WaitRefresh → 循环
           │
           └─ 全部忙线 → E_AllTeamsBusy
                   │
                   └─ E_TimerStart（记录 now + interval）
                           │
                           └─ LR_NavigateToUnderground → 活动页面
                                   │
                                   └─ LR_IsEventPage → E_CheckTimerExpired
                                           │
                                     ┌─────┴──────────┐
                                     │                │
                                命中(过期)        未命中(未到)
                                → E_GoHome       → LR_SelectDifficulty
                                → 回本丸             → 选难度 → 出阵
                                → Expedition
                                → 检查远征          若干轮战斗后回到活动页面
                                → ...                    │
                                                         │
                                            LR_IsEventPage → E_CheckTimerExpired
                                                    │
                                              ┌─────┴──────────┐
                                              │                │
                                         命中(过期)        未命中(未到)
                                         → 回本丸远征      → 继续出阵
```

**关键点**：计时器检查不在 `LR_IsHome`（本丸检测），而在 `LR_IsEventPage`（活动页面检测）。LR 不会无故回本丸，只在倒计时归零时才主动导航回去。
