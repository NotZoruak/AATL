# v0.12.0-beta.3

## 【 v0.12.0-beta.3 】 (2026-08-27)

### 新增

* 新增“更新数据”任务，可选择识别仓库、刀帐或仓库+刀帐，并支持每次、每天、每周的触发间隔设置。
* 新增刀剑掉落播报，可在全局设置中自定义需要播报的刀剑名称。
* 新增刀剑初获取自动截图，截图将保存至 `debug/sword_drop/` 目录。

### 修复

* 修复合战场、地下城在使用加速符修复时，因过早读取修复信息而显示“信息识别失败”的问题。
* 修复刀剑特化和极化动画被误识别为刀剑掉落的问题。

### 优化

* 刀帐自动识别不再生成工作记录，避免数据采集任务混入任务统计。

**版本变更**：v0.12.0-beta.2 → v0.12.0-beta.3
