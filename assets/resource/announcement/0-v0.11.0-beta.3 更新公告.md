## 【 v0.11.0-beta.3 】 (2026-08-21)

### 工作记录

* 将任务概况中的“提前结束次数”改为“返回本丸次数”，由确认返回本丸日志统一统计
* 保留刀装近破坏撤退等异常的特殊情况记录
* 修复运行中任务与正常完成任务的状态显示
* 远征倒计时结束继续计入后勤记录，小判箱连续重复识别合并为一次掉落

### 保存记录

* 新增已保存记录列表，支持保存单条或合并同名任务记录，并可查看、合并、删除和清空
* 保存记录独立于日志文件，不受日志自动清理影响

### 界面优化

* 后勤记录重新分组：倒计时结束、检查队伍状况和刷花一组，派遣远征与详细派遣信息一组
* 压缩工作记录列表高度，在保留现有信息的同时显示更多记录
* 移除工作记录页面顶部的数据存放位置与自动清理说明

**版本变更**：v0.11.0-beta.2 → v0.11.0-beta.3
