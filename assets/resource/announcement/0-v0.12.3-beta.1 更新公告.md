# v0.12.3-beta.1

## 【 v0.12.3-beta.1 】 (2026-08-29)

### 新增

* 支持 Apple Silicon macOS 版本，可通过双击 `MATR.app` 启动。
* GitHub Actions 自动构建 Windows x64 与 Apple Silicon macOS 安装包。

### 修复

* 修复 Windows 版本双击启动时出现命令行窗口的问题。
* 修复 Windows 可执行文件图标未正确显示的问题。
* 修复 macOS Bundle 版本字段不符合规范导致应用包信息无效的问题。

### 优化

* Windows 与 macOS 压缩包文件名增加平台标识，便于区分下载版本。
* 优化非 Windows 环境下的运行时路径与字体兼容处理。
* 全量重构了习合搓糖任务。

**版本变更**：v0.12.2 → v0.12.3-beta.1
