# v0.12.0

## 【 v0.12.0 】 (2026-08-27)

### 新增

* 新增「江户潜入」活动任务，支持行动策略、点位识别、门票处理、同步后勤与远征智能调度。
* 自定编队新增「仅使用编队记录」和「仅记录编队」两个互斥选项，支持按目标部队编号使用或保存对应的游戏部队记录。

### 修复

* 修复习合搓糖开启时，锁定且达到乱舞等级上限的目标刀剑反复进入、退出习合操作页面的问题。

### 优化

* 优化刀解清仓任务的页面切换等待与点击稳定性，减少刀种筛选、确认解体及进入邮箱过程中的误操作。

**版本变更**：v0.11.2 → v0.12.0
