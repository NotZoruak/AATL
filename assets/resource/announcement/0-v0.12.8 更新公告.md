# v0.12.8-beta.2

## 【 v0.12.8-beta.2 】 (2026-09-02)

### 新增

* 卡死自动恢复事件会同时显示在实时日志面板，并写入工作记录可解析的日志。

### 修复

* 补全“卡死重启”对全部 `FallbackWait` 流程的覆盖，修复更新数据等流程卡死后无法触发重启的问题。
* 移除卡死恢复过程中重复的 ADB 警告工作记录，避免一次卡死生成多条重复事件。
* 修复江户潜入在步数为 0 时卡住的问题。

### 优化

* 整体优化了 GUI 布局与任务选项设计。
* 优化了习合搓糖任务的使用体验
* 优化了海陆联队中部队交替选项的使用体验

**版本变更**：v0.12.71 → v0.12.8
