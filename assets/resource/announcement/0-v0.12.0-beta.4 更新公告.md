# v0.12.0-beta.4

## 【 v0.12.0-beta.4 】 (2026-08-27)

### 新增

* 新增「江户潜入」活动任务，固定支持 E4（超难）出阵，并兼容选择部队、更换队长、不买门票、同步后勤与远征智能调度。
* 新增江户城行动选择：自动识别目前位置、剩余行动次数与已走过点位，支持直奔王点、保守、均衡、激进四种行动策略。
* 行动中自动记录点位类型并计算进王概率；非激进策略在仅余一步且无法进入王点时自动返回本丸。

### 修复

* 修复习合搓糖开启时，锁定且达到乱舞等级上限的目标刀剑反复进入、退出习合操作页面的问题。

### 优化

* 优化刀解清仓任务的页面切换等待与点击稳定性，减少刀种筛选、确认解体及进入邮箱过程中的误操作。

**版本变更**：v0.12.0-beta.3 → v0.12.0-beta.4
