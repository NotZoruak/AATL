# 现行更新方式

MATR 目前支持以下四种更新方式。更新前请先停止正在运行的任务。如果担心更新过程中数据丢失，可以提前手动备份 `config` 文件夹。

## 🌍 GitHub 在线更新

在【更新设置】中，将【资源下载源】切换为【GitHub】，通过程序内的更新功能下载并安装更新。

此方式免费使用，下载速度受网络环境影响，部分地区可能出现连接失败或下载缓慢。

## 🔑 Mirror 酱在线更新

[已有 Mirror酱 CDK？前往 Mirror酱 高速下载](https://mirrorchyan.com/zh/projects?rid=MATR&source=matr-announcement)

在【更新设置】中，将【资源下载源】切换为【Mirror 酱】，并填写有效的 **CDKey**，通过程序内的更新功能下载并安装更新。

Mirror 酱提供付费下载加速服务，适合访问 GitHub 困难的用户。

**MATR 本体免费开源，全部功能无须付费解锁。** Mirror 酱是可选的更新渠道。

## 📦 解压覆盖更新

下载适合自己系统的 MATR 发布压缩包后：

1. 完全退出 MATR。
2. 解压压缩包，将其中的内容复制到原 MATR 安装目录。
3. 出现同名文件提示时，选择替换。
4. 覆盖完成后，重新启动 MATR。

请确认覆盖的是原安装目录，避免把新版解压到其中的另一层文件夹，导致启动的仍是旧版。

## 🖱️ 拖入压缩包更新

下载适合自己系统的 MATR 发布压缩包后，**无须手动解压**，直接将压缩包拖入 MATR 主界面，按照程序提示完成更新。

手动下载时，请选择对应系统的发布压缩包，不要下载 GitHub 自动生成的 `Source code` 源码包。

## 版本说明

- **正式版**：不会进行版本内更新，稳定性高，推荐选择该版本
- **公测版**：功能经过验证，稳定性较高但仍在持续接受bug反馈并实时修复
- **内测版**：包含最新功能，可能存在未知 bug，会根据接收到的测试反馈实时更新修复，不建议普通用户下载使用
