# v0.13.0-beta.1

## 【 v0.13.0-beta.1 】 (2026-09-05)

### 修复

* 修复异步任务队列提前进入停止流程的问题，同时修复工作记录保存与日志导出反馈入口异常。
* 修复启动时资源路径解析错误，避免在程序根目录生成无用的 `resource` 文件夹。
* 修复模拟器自动连接失败后未按配置重试的问题。
* 修复开启卡死重启后，一键日课部分 hub 超时未触发游戏重启的问题。
* 修复部分模拟器缺少 `monkey` 命令或无法解析包名启动 Intent，导致游戏重启失败的问题。

### 优化

* 优化卡死恢复日志，区分模拟器重启失败与游戏启动失败；模拟器恢复成功但游戏启动失败时，继续交由任务流程尝试进入主枢纽。

### 依赖更新

* 升级 MFAAvalonia 至 v2.16.1，并适配新的任务设置与发布结构。
